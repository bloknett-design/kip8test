# Task 416 — столбец E «сокращение» в «Список_И_и_ПЗ»: краткие названия в компактных показах

**Заявка:** «Я добавил в таблицу Список_И_и_ПЗ новый столбец E
"сокращение", в нём содержаться сокращённые названия, которые нужно
применять на странице Табель учёта рабочего времени, в окне
мероприятий и в мини окнах шахматки и фамилий работников».

## Что изменилось

Записи инструктажей/проверок знаний в КОМПАКТНЫХ показах теперь
показывают **сокращение** из столбца E листа «Список_И_и_ПЗ» (запись
сопоставляется пункту по теме — та же нормализация, что у групп
карточки: регистр/пробелы/«ё»). Нет соответствия, пустая ячейка E
или старый сервер без поля — **полное название** (как раньше).

Где применяются сокращения:

1. **Печать табеля** («График работы — табель учёта рабочего
   времени») — список мероприятий месяца под сеткой: «И · Инстр. ОТ ·
   ФИО» вместо полного названия;
2. **Окно «Мероприятия»** (месяц, бар под кнопками);
3. **Мини-окна шахматки**: тултип бейджа ячейки («И — Инстр. ОТ») и
   окно «Мероприятия в этот день»;
4. **Мини-окна фамилий**: попап карточки из сетки — заголовки групп
   шаблона показывают сокращение, а ПОЛНОЕ название остаётся в
   нативном тултипе (title); строки мероприятий/инструктажей —
   сокращение;
5. **Страница «Работники»** — те же строки карточки (плоский список).

**НЕ тронuto:** форма «+ Инструктаж…» — select остался по ПОЛНЫМ
названиям (выбор пункта), подсказка «раз в N…» прежняя; окно выбора
кодов дня — не инструктажи.

## Серверные шаги

**ДА — обновить WorkSchedule.gs** (Apps Script проекта табель_КИП_ИОС):

1. Вставить новый `WorkSchedule.gs` (из репозитория) в редактор
   Apps Script;
2. **Новая версия развёртывания** (Deploy → Manage deployments →
   Edit → New version);
3. В таблице «Список_И_и_ПЗ» столбец E уже заполнен пользователем —
   больше ничего не требуется (заголовок E «сокращение» уже стоит;
   `instrListInit` при повторном запуске данные столбца E НЕ
   затирает — чистятся только A..D).

До обновления сервера приложение работает как раньше (полные
названия) — поле «сокращение» просто не приходит.

## Что проверять

1. Навести на бейдж И/ПЗ в сетке — всплывашка «И — <сокращение>»;
2. Клик по ячейке с мероприятием — окно «Мероприятия в этот день» —
   строки с сокращениями;
3. Окно «Мероприятия» в баре — строки месяца с сокращениями;
4. Клик по фамилии — заголовки групп с сокращениями, наведение на
   заголовок показывает полное название;
5. «Работники» → карточка — плоские строки «сокращение · дата»;
6. «Печать» — список мероприятий с сокращениями;
7. «+ Инструктаж…» — в select по-прежнему полные названия.
