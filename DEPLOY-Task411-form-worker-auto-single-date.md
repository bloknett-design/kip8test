# Task 411 — форма инструктажа/ПЗ: работник из карточки, одна дата проведения

**Заявка:** «Нужно скорректировать форму добавления инструктажа и проверки знаний в
картах работников. Форма открывается в каждой карте работника, поэтому выпадающий
список с фамилиями в ней не нужен, работник должен автоматически вычисляться из его
карты, где открыта форма добавления. В поле Инструктаж / проверка знаний должен быть
выпадающий список из таблицы Список_И_и_ПЗ. Поле выбора даты должно быть одно, нет
необходимости указывать период проведения инструктажа или проверки знания, они
проводятся одним днём, просто выбирается дата проведения».

## Что сделано (только клиент — index.html; сервер НЕ менялся)

### 1) Работник — автоматом из карточки (список фамилий убран)

- выпадающий список `#wsTrTabNo` с фамилиями **удалён** — форма всегда
  открывается в контексте конкретного работника (карточка «Работники»,
  попап ячейки шахматки, правка записи);
- вместо него — **статичная строка «ФИО · таб. №»** `#wsTrEmp` (стиль
  шторки увольнения, Task 318) в собственной строке формы на всю ширину;
  подпись поля — **«Работник»** (было «Таб. №»);
- значение для submit хранит **скрытое поле** `#wsTrTabNo` (input hidden;
  код submit не менялся);
- `openTrainingForm`: работник = `prefillTab` кнопки входа / ячейки
  (`onEmpAddInstruction` / `onEmpAddTraining` / `onPopupAddEvent`) или
  `таб_номер` правимой записи (`editTraining`); поиск по `_EMPLOYEES`;
  работника нет — тост «Работник не определён — откройте форму из
  карточки работника», форма не открывается (защита прямых вызовов);
- правка записи показывает работника **из записи** (проверено: запись
  другого работника открывает его строку);
- фокус после открытия — первый видимый контроль режима (select пункта
  в instr / «Тип» в событии), не список работников.

### 2) Поле «Инструктаж / проверка знаний» — список Список_И_и_ПЗ

Выбор пункта «Список_И_и_ПЗ» (Task 410) сохранён без изменений: строгий
select всех пунктов с группами «Инструктажи» (2) / «Проверка знаний» (3),
тип записи = «вид» пункта, подсказка «раз в год · Основание: …»,
«вне списка» при правке старых записей.

### 3) Одна дата — «Дата проведения» (без периода)

- instr-режим (`_applyTrFormMode`): поле даты подписано **«Дата
  проведения»**, поля **«Дата окончания» и «Длит., дн» скрыты** —
  инструктаж/ПЗ проводится одним днём;
- `submitTrainingForm`: в instr-режиме **дата_окончания = дата_начала,
  длительность_дней = 1** всегда — даже если скрытые поля хранят значения
  прошлой правки многодневного мероприятия;
- валидация даты — по режиму: «Укажите дату проведения» (instr) /
  «Укажите дату начала» (событие);
- форма события («+ Мероприятие…», попап ячейки) — **период сохранён**
  (обучение может быть многодневным): «Дата начала» / «Дата окончания» /
  «Длит., дн» видимы, значения уходят как введены.
