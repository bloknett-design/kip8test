## ЧТО СДЕЛАНО (клиент — работает сразу после пуша; серверных шагов НЕТ)

### 1. Легенда сокращений (кнопка «Легенда», ряд 2 бара)
- Кнопка-переключатель «Легенда» в ряду 2 (после вкладок «Месяц»/«Год»),
  видна ВСЕМ уровням доступа, `aria-pressed`.
- Шторка **#wsLegendDrawer** — по принципу окна итогов: десктоп — панель
  выезжает СПРАВА (margin-right 0.28s, сетка сжимается, дни прокручиваются
  под ней), мобайл — fixed-оверлей ~86vw со скруглением/тенью; левый
  стальной бортик. **Взаимоисключающая с «Итогами учёта»** (открытие
  закрывает другую шторку; закрытие — повторный клик/Esc).
- Контент `_renderLegendSheet`: коды дней Т-12/Т-13 И коды мероприятий —
  динамически из справочника «Коды_статусов» (живые цвета — свотчи);
  секция «Обозначения в шахматке» (бейдж плановой смены Д/Н в отпусках,
  подсветка «сегодня», рамки выходных 2px, «24*» сокращённый день,
  «(−N праздн.)» ст. 120 ТК РФ, лимит 42 ст. 125 ТК РФ, зебра/перекрестье).
- Имя `_renderLegendSheet` — не конфликтует с могильником Task 252
  (старая статичная легенда под шахматкой не вернулась — тест жив).

### 2. «Сотрудник» → «Работник» (раздел Табель, все склонения)
- Видимые строки UI: шапка сетки («Работник», сужение «Рабо»), шапки
  итогов ×3 (месяц/год/архив), шторки («Новый работник», «Правка
  работника», «Увольнение работника», лейбл «Работник»), тосты («Работник
  не найден», «Данные работника обновлены», «Работник добавлен», «Работник
  уволен и убран из графика», «Выберите работника»), подтверждение
  увольнения, пустые состояния («Нет активных работников»/«Нет
  работников», «Работники вида…»), печать (шапка «Работник»), подсказки
  вида/«Обновить», aria-подписи.
- НЕ тронуты: идентификаторы (`ws-emp-*`, `_EMPLOYEES`), серверные
  контракты (лист Google Sheets «Сотрудники», payload-ключи, серверные
  сообщения валидации), другие модули. Комментарии кода с историей задач —
  сохранены (не видны пользователю).

### 3. Карточка read-only + страница «Работники»
- **Карточка в шахматке — ТОЛЬКО ЧТЕНИЕ для ВСЕХ уровней** (заявка): у
  редакторов больше НЕТ «Правка данных…»/«Уволить…»/«+ Отпуск…»/
  «+ Мероприятие…»/✎/✕. `_renderEmpPopup` — обёртка
  `_renderWorkerCard(tabNo, false)`.
- **Кнопка «Работники» в ряду 1** бара (после «Печать», иконка людей) —
  только редакторам (видимость в `init` + `_onRoleUpdate`, двойная защита
  в `openWorkersPage`). Заголовок шапки сетки «Работник +» — тот же переход.
- **Страница #page-ws-workers**: шапка со шевроном, крошки
  «…/Табель/Работники», кнопка «+» (шторка создания), счётчик «N
  работников», полные карточки `.ws-wcard` в порядке строк шахматки
  (сменные по сменам → дневные → алфавит): «Правка данных…» (updateEmployee,
  таб. № readonly PK), «Уволить…», отпуска года (✎/✕/«+ Отпуск…»),
  мероприятия месяца (✎/✕/«+ Мероприятие…»). Карточки обновляются вместе
  с сеткой (`_renderGrid → _renderWorkersIfOpen`); после мутаций —
  `loadGrid(true)` (страница перерисовывается автоматически).
- Страница зарегистрирована: `_WORK_SCHEDULE_PAGES` (права наследует
  табель), `PAGE_PARENTS`/`PAGE_LABELS` (крошки), хук `navigateTo`
  (`onWorkersPageOpen` — прямой заход по URL). Зрители: кнопка скрыта,
  карточки (если открыть напрямую) — без кнопок правки.
