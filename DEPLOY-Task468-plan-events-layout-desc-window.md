## Суть изменений

Заявка: «Ширину столбца "Мероприятия" сделай по самому длинному тексту,
всю таблицу — влево экрана, а справа от таблицы на всё оставшееся место
размести окно с Описанием раздела и его функционала.»

| Элемент | Было (Task 460–464) | Стало (Task 468) |
|---------|---------------------|------------------|
| Ширина таблицы | `.pe-table { min-width: 100% }` растягивала столбец «Мероприятия» (auto) на всю свободную ширину карточки — таблица «плавала» по ширине окна | **Строго по контенту** (`width: max-content`, min-width удалён): столбец — по самому длинному наименованию |
| Положение таблицы | Карточка на всю ширину раздела | **Прижата влево экрана** (`.pe-layout .pe-card { flex: 0 0 auto }`) |
| Место справа от таблицы | Пустое | **Окно «Описание раздела»** (`.pe-desc-card { flex: 1 1 280px }`): описание раздела + функционал (отметки Task 463, правка/мобильный вид Task 464, образец Task 460) |
| Узкие экраны | — | `< 1200px`: окно описания переезжает ПОД таблицу; **мобильный вид Task 464 (≤1023px: столбец + один месяц, селектор «Месяц») не меняется** |

Подробности:

- Новый контейнер `.pe-layout` (flex-строка, внешний отступ `0 12px`
  перенесён сюда с `.pe-card`) → карточка таблицы слева + окно
  описания справа; на `< 1200px` складывается в колонку.
- Наименования мероприятий — в одну строку (nowrap Task 464 жив),
  таблица не создаёт горизонтального скролла.
- JS отметок (`PlanEventsData`, диалоги отметки/правки, кнопка
  «Обновить»), мобильный селектор месяца, СМ-версия Apps Script —
  НЕ менялись.

## Проверка после деплоя

1. Открыть раздел «Плановые мероприятия» (тёмная и светлая темы).
2. Таблица прижата к левому краю, столбец «Мероприятия» по самому
   длинному тексту (без растяжения), все 12 месяцев на месте.
3. Справа от таблицы — окно «Описание раздела» с описанием и списком
   функционала; прокручивается, если текст выше окна.
4. Сузить окно браузера до ~1100px — описание переезжает под таблицу.
5. Мобильный вид (≤1023px): столбец «Мероприятия» + один месяц,
   селектор «Месяц», описание под таблицей — как в Task 464.
6. Отметки выполнения работают как раньше (клик по ячейке месяца,
   правка/удаление отметки, кнопка «Обновить»).
