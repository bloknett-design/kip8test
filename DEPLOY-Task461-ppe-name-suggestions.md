# Task 461 — Динамический выпадающий список наименований СИЗ (форма «Работники»)

**Заявка:** «В разделе Работники в форме добавления СИЗ, выпадающий список наименования СИЗ должен формироваться автоматически в зависимости от содержания столбца "наименование_СИЗ" расположенного на листе "СИЗ" файла табель_КИП_ИОС. То есть из всего списка наименования СИЗ в столбце "наименование_СИЗ", в выпадающем списке формы должны перечислятся все разные СИЗ, но естественно в одном наименовании, без повторения.»

## Суть

- Поле «Наименование СИЗ» шторки «Новое СИЗ» / «Правка СИЗ» — прежний
  input + datalist (свободный текст НЕ запрещён), но подсказки
  `#wsPpeNameList` теперь формируются ДИНАМИЧЕСКИ при каждом открытии
  шторки (`WorkSchedule._fillPpeNameOptions`, вызов из `openPpeForm` —
  создание и правка).
- Источник — уже существующий кэш `this._PPE` (`workSchedule.listPpe`,
  обновляется `loadGrid` → `_loadPpe` после каждого добавления/правки/
  удаления): поле `наименование` записей = столбец E «наименование_СИЗ»
  листа «СИЗ» табель_КИП_ИОС.
- Правила формирования: УНИКАЛЬНЫЕ наименования без повторов (одно и то
  же СИЗ у разных работников — одна строка), регистр не различается
  (хранится первое встреченное написание), пробелы обрезаются, пустые
  пропускаются, сортировка по алфавиту `localeCompare 'ru'`.
- Пустой лист «СИЗ» (нет записей / офлайн до первой загрузки) — datalist
  НЕ перезаписывается: в HTML остаётся запасной статичный набор из 8
  позиций образца (Task 392).
- СЕРВЕР НЕ МЕНЯЕТСЯ: `listPpe` уже отдаёт все записи листа; серверных
  шагов НЕТ (srvVer без изменений).
