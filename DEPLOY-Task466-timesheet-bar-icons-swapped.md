Подробности:

- CSS: правило `#wsEventsPanel .ws-bar-exp { right: 27px }` УБРАНО
  (значок раскрытия возвращается в самый угол на базовые 2px + 1px рамка
  = 3px от края); вместо него — `#wsEventsPanel .ws-bar-print { right:
  27px }` (печать слева от раскрытия, зазор 3px).
- Размеры/стили/логика НЕ менялись: обе кнопки 22×22, клик по принтеру —
  тот же диалог «Печать / Сохранить PDF / Сохранить Excel / Отмена» с
  предпросмотром книжного A4-листа списка мероприятий открытого месяца;
  клик по шеврону — раскрытие окна; прикол к видимой грани при прокрутке
  — на обоих значках.
- Окно «Нормы» не тронуто (один значок раскрытия в 3px от краёв).
- JS-логика не менялась — порядок значков задаётся только CSS (оба
  значка absolute внутри скроллера).

## Шаги деплоя

НЕ ТРЕБУЮТСЯ. Клиент задеплоится GitHub Pages автоматически после пуша
(CI: Tests + pages). Service Worker поднят до `kipia-test-v690`
(kip8test) / `kipia-v502` (kip8) — у пользователей кэш обновится при
следующем открытии приложения (в течение пары переходов).

## Проверка после деплоя

1. Открыть раздел «Табель учёта рабочего времени». В правом верхнем углу
   окна «Мероприятия» — пара значков: СЛЕВА принтер, СПРАВА шеврон
   раскрытия (у самого края), зазор между ними ~3px.
2. Нажать принтер → диалог «Предпросмотр печати / Мероприятия — месяц
   год г.» открывается как раньше (кнопки печати/сохранения работают).
3. Нажать шеврон → окно раскрывается, повторный клик — сворачивается.
4. Окно «Нормы» — по-прежнему один значок раскрытия в углу.
