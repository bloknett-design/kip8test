# DEPLOY — Task 463: «Плановые мероприятия» — отметки выполнения + архив в файле Мероприятия_КИП_ИОС

**Дата:** 02.10.2026. **Что менялось:** клиент (index.html — уже в репозитории,
деплой GitHub Pages автоматически) + СЕРВЕР Apps Script (по этой инструкции —
2 шага: файл PlanEvents.gs + маршрутизация Code.gs + init-скрипт листа «Архив»).

## Суть

Раздел «Плановые мероприятия» (Task 460 — таблица-образец, Task 462 — право
`plan.events`) становится ИНТЕРАКТИВНЫМ:

| Элемент | Поведение |
|---------|-----------|
| Ячейка месяца (96 шт.) | ТУСКЛЫЙ крестик — «ещё не выполнено» |
| Клик по ячейке | Диалог: «Отметка выполнения» — наименование мероприятия, месяц, **дата выполнения** (по умолчанию сегодня, можно изменить) |
| Подтверждение («Отметить») | В ячейке вместо крестика — **ЗЕЛЁНАЯ ГАЛОЧКА**; отметка (наименование + дата) сохраняется в **архив файла Мероприятия_КИП_ИОС** |
| Клик по отмеченной | Тост «Уже отмечено: выполнено ДД.ММ.ГГГГ» (повторной записи не создаётся) |
| Кнопка «Обновить» в шапке | Перезагрузка отметок с сервера (тост «Отметки обновлены») |
| Ошибка сети/сервера | Тост «Не удалось отметить: …», ячейка остаётся крестиком |
| «Старый сервер» (до шагов ниже) | Автозагрузка ТИХО — крестики без отметок; явная отметка → тост с ошибкой |

**Архив** — лист «Архив» файла Мероприятия_КИП_ИОС
(`https://docs.google.com/spreadsheets/d/1uX8Bz6FBS9HniZfWQnHeeyccTwwjwyvpPFWyFkIclCs/edit`):

| Столбец | Содержимое |
|---------|-----------|
| A `id` | автоинкремент (max + 1) |
| B `дата_выполнения` | дата выполнения (текст `ГГГГ-ММ-ДД`) |
| C `мероприятие` | наименование из таблицы раздела |
| D `год` | 2026 |
| E `месяц` | 1..12 |
| F `email` | кто отметил (из сессии) |
| G `время_отметки` | timestamp момента отметки |

Доступ — право `plan.events` (Task 462): и просмотр отметок, и отметка
выполнения — одним правом. Сервер идемпотентен: повторный `mark` того же
(год, месяц, мероприятие) НЕ создаёт дубль — возвращает существующую запись
(`already: true`), ретраи клиента и повторные клики безопасны.

**Год плана** фиксирован заголовком таблицы «2026 год» (Task 460); отметки
хранятся с годом — при смене года в таблице (новая заявка) архив сохранит
историю. Ручные правки листа поддерживаются (даты и текстом, и Date-объектом;
битые строки молча пропускаются).

## Шаги деплоя

### 1. Apps Script: файл PlanEvents.gs

Открыть Apps Script (script.google.com, проект развёртывания AKfycbyt… —
ОДИН проект на kip8 и kip8test), **+ → Создать файл «PlanEvents.gs»**, вставить
содержимое `scripts/PlanEvents.gs` из репозитория kip8test ЦЕЛИКОМ.

### 2. Apps Script: маршрутизация Code.gs

В файле `Code.gs` того же проекта добавить ДВА case в `doPost` (перед
`default:`) — эталон `scripts/Code.gs` в репозитории уже содержит их:

```js
      // === Плановые мероприятия: отметки выполнения (Task 463) ===
      case 'planEvents.list':
        return _json(PlanEvents.list(payload));

      case 'planEvents.mark':
        return _json(PlanEvents.mark(payload));
```

### 3. Новая версия развёртывания

Deploy → Manage deployments → ✏️ (Edit) → Version: **New version** → Deploy
(тот же URL AKfycbyt… — один деплой на kip8 и kip8test).

### 4. Лист «Архив» (одноразовый скрипт)

**+ → Создать файл «PlanEventsInit.gs»**, вставить содержимое
`scripts/PlanEventsInit.gs` из репозитория, выполнить функцию
**`planEventsDeploy`** (первый запуск попросит авторизацию — разрешить).
Скрипт идемпотентен: создаст лист «Архив» с заголовками (7 колонок,
текстовый формат дат B/G — паттерн Task 304) и ничего не перезапишет, если
лист уже есть. После выполнения файл можно удалить из проекта — копия-эталон
в `scripts/` репозитория.

Проверка: функция `planEventsStatus` — наличие листа, заголовки, число строк.

### 5. Клиент (kip8test)

Уже в репозитории (SW kipia-test-v687), GitHub Pages деплоится автоматически
CI. Пользователям: Ctrl+Shift+R ×1–2.

**Порядок шагов 1–4 любой относительно клиента:** между обновлением страницы
и сервером работает тихая деградация (крестики без отметок) — ничего не
ломается.

1. Войти под ролью с галочкой `plan.events` → «Документация ИОС» →

2. Клик по ячейке месяца → диалог с наименованием, месяцем и датой (сегодня)
   → «Отметить» → в ячейке ЗЕЛЁНАЯ галочка, тост «Выполнение отмечено».
3. Открыть файл Мероприятия_КИП_ИОС → лист «Архив»: строка с наименованием,
   датой выполнения, годом, месяцем, email и временем отметки.
4. Клик по отмеченной ячейке → тост «Уже отмечено: выполнено …», дубль в
   архиве НЕ появился.
5. Кнопка «Обновить» (⟳ в шапке) → отметки других пользователей подтягиваются.
6. Повторное открытие страницы → галочки на месте (загружаются с сервера).
