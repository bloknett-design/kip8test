# DEPLOY Task 289 — счётчик «За неделю» из суточных данных (форма недели убрана)

**Дата:** 2026-09-01
**Задача:** По заявке пользователя — форма передачи показаний «за неделю»
убрана. Вместо неё — счётчик показаний за календарную неделю (7 дней,
пн–вс) на основе данных, внесённых за сутки: справа от заголовка
«Хронология показаний» (над «Показания, т»). Логика подсчёта количества
дней за месяц теперь учитывает все дни включительно: период
01.08–31.08.2026 = 31 полный день (не 30). Форма «за месяц» и суточная
логика — без изменений.

## Что нужно сделать пользователю

**Сервер (Apps Script) — 1 файл:**

1. Открыть проект Apps Script (AKfycbyt…).
2. Файл `FlowmeterArchive.gs` — заменить содержимое на новый
   (из репозитория `kip8test/scripts/FlowmeterArchive.gs`).
   Единственное изменение: `daysBetween` для записей «за период»
   (неделя/месяц) теперь +1 (дни включительно).
3. **«Новая версия»** развёртывания (НЕ новое развёртывание!) —
   как в Task 286.

**Фронтенд:**

4. Открыть приложение в браузере.
5. **Ctrl+Shift+R** — подождать 3–5 секунд — **Ctrl+Shift+R** ещё раз
   (обновление Service Worker v534 → v535).
6. Открыть «Расходомеры хозрасчётные» → карточка «Хозрасчёт №1»:
   - в строке «ХРОНОЛОГИЯ ПОКАЗАНИЙ» справа — «За неделю: … т»
     (сумма суточных показаний текущей недели);
   - «Изменить показатели» → chips только «За сутки / За месяц»;
   - ввод «за месяц» — как раньше (Период с/по, прошлый месяц).

Если после двух Ctrl+Shift+R изменения не видны — закрыть вкладку
целиком и открыть заново (или F12 → Application → Service Workers →
Unregister, затем перезагрузка).
