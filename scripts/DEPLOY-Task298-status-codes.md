## Что сделано

Состав кодов статусов приведён к официальной семантике Т-12/Т-13
(Постановление Госкомстата №1 от 05.01.2004) по решению пользователя:

| Код | Было (10) | Стало (16) |
|-----|-----------|------------|
| Д | День | День 12-час (7:30–19:30) — только сменный персонал |
| Д8 | — | День 8-час (7:30–16:30) — дневной персонал |
| Д7,2 | — | День 7,2-час (7:30–15:48) — пятница/предпраздничный |
| Н | Ночь | Ночь 12-час (19:30–7:30) |
| д | — | День в выходные/праздники (сменный 12-час; дневной — часы в комментарии) |
| н | — | Ночь в выходные/праздники |
| О | Отпуск | — (заменён на ОТ) |
| ОТ | Отгул | Отпуск, ежегодный основной оплачиваемый |
| У | — | Учебный отпуск (с сохранением среднего заработка) |
| ОВ | — | Отгул, дополнительные выходные дни (оплачиваемые) |

Коды **регистрозависимы**: «Д» (плановая смена) ≠ «д» (работа в
выходной/праздник). Цвета новых кодов подобраны (Q2) — пользователь
скорректирует при необходимости.

## Изменения кода

- **WorkSchedule.gs**: генерация отпусков пишет «ОТ» вместо «О»
  (6 мест generateMonth, шаг 4.5 + очистка устаревших);
  `setManualEntry` валидирует код по листу «Коды_статусов»
  (новый `_validateStatusCode`, fail-closed: листа нет/код неизвестен →
  правка отклонена с `unknown_статус`); комментарии обновлены.
- **index.html**: пустые ячейки плана отпуска показывают «ОТ»
  (рендер + тултип «заполнится кодом «ОТ» при «Сформировать»»);
  fallback-набор при недоступности сервера = 16 новых кодов; select
  «Статус» в расширенной правке («Дополнительно…») теперь строится
  ДИНАМИЧЕСКИ из справочника (`_fillStatusSelect`), статический HTML
  со старыми 10 кодами удалён; легаси-значение добавляется временной
  опцией «(нет в справочнике)».
- **sw.js**: kipia-test-v539 → v540.
- **Тесты**: 1324 → 1345 (+21: 10 серверных `_validateStatusCode` +
  11 клиентских инвариантов; ассерты «О»→«ОТ» в 2 файлах; SW v540 в
  6 файлах). Верификация: browser-check Playwright 29/29 + VLM ×3.

### Шаг 2. Миграция «О» → «ОТ» в листе «Записи_графика» — вручную

В БД 2570 записей, из них **21 со статусом «О»** (авто-отпуска 2026
г.; записей «П» и «*» нет). Править → Ctrl+H (Найти и заменить):

- **Найти:** `О` → **Заменить:** `ОТ`
- **Область:** заранее выделите ТОЛЬКО колонку C (статус), иначе
  замените «О» внутри дат/комментариев!
- «С учётом регистра» — включить (иначе затронете «ОБ», «ОТ», «ОЖ»).

Проверка после: в колонке C не осталось одиночных «О» (фильтр по
столбцу C → значение «О» → пусто).

## Порядок шагов

Шаги 1–2 (листы) можно делать в любом порядке относительно 4–5
(сервер/фронтенд) — переходный период безопасен:
- старый сервер + новый лист: старые коды валидируются, новые
  появятся в попапе (валидация их пустит только после Шага 4);
- новый сервер + старый лист: наоборот — ничего не ломается.
Единственное «нельзя»: НЕ запускать «Сформировать» на месяце с
отпуском ДО Шага 2 (миграция) — покрытые отпуском дни обновятся на
«ОТ» сами, но дни с УДАЛЁННЫМ периодом останутся «зависшими» «О».
