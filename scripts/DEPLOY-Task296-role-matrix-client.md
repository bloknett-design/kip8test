# Task 296 — Этап 4: клиент на серверной карте прав (деплой и проверка)

## Что это

Клиент (index.html) переключён с **захардкоженной** карты ролей на
**серверную карту прав из матрицы KIP8_Access** (action `getMyAccess`,
появился в Этапе 3 / Task 295). Теперь правка галочки в таблице меняет
видимость разделов и кнопок сайта **без деплоев и релизов PWA**.

| Что | Как теперь работает |
|---|---|
| Видимость разделов (сайдбар, дашборд) | по правам матрицы: `calc.view` → калькуляторы, `library.view` → библиотека, `kipios.view`/`kipios.restricted` → КИП ИОС, `secret.view` → секретные, `whatsnew.view` → «Что нового», `charts.view` → графики, `flowmeter.view` → расходомеры, `workschedule.view` → график работы |
| Кнопка «Ввести показания» | право `flowmeter.input` из матрицы (было: захардкоженный список «дежурный + Админ») |
| Обновление карты | при входе, каждой загрузке страницы и каждым heartbeat (5 мин) — правка галочки доезжает до открытого клиента ≤ ~10 мин (TTL серверного кэша 5 мин + heartbeat 5 мин) |
| Быстрый старт из кэша | кэш `kip8_my_access` в localStorage — разделы не «мигают» до ответа сервера |
| Если карта недоступна (старый сервер / сеть) | сайт работает по прежней легаси-карте — сервер всё равно проверяет каждый запрос, клиентская видимость прав не даёт |
| Роли нет в матрице / матрица сломана | все матричные разделы скрыты (fail-closed — как на сервере) |
| Админ | не тронут: `['*']` + сервер принудительно даёт админу все права |

## Как теперь менять права (полный цикл, без релизов)

1. Открыть таблицу KIP8_Access → лист matrix → поставить/снять галочку.
2. Подождать ≤ 5 минут (серверный кэш) или выполнить
   `roleMatrixInvalidateCache()` в редакторе Apps Script — мгновенно
   для сервера.
3. Клиент подхватит при следующем входе/загрузке; в открытой вкладке —
   ≤ ~10 мин (heartbeat) или после обновления страницы.

## Если что-то пошло не так

- Все закрытые разделы стали недоступны ВСЕМ → матрица не читается.
  `roleMatrixDebug` в редакторе покажет причину (это fail-closed по
  дизайну — и на сервере, и теперь в клиенте).
- Кнопка «Ввести показания» не появилась у нужной роли → проверьте
  галочку `flowmeter.input` в matrix (лист matrix, колонка права).
  Диагностика в браузере (F12 → Console):
  `KipAuth._serverAccess` — что прислал сервер (права в permissions),
  `KipAuth._serverPerm('flowmeter.input')` — true/false/null
  (null = карта не получена, работает легаси-список).
- Сайт открылся, но разделы «мигают»/исчезли → посмотрите Console:
  предупреждение `[KipAuth._fetchMyAccess]` означает, что карта не
  получена (сеть/старый сервер) — работает легаси-карта, это не поломка.
