## 2. Красный «пора вводить» для недельных/месячных (клиент, PWA)

Правило уже работало с Task 357 (проверено тестами), по заявке **закреплено и укреплено**:

| Период | Красный, когда | Зелёный, пока |
|---|---|---|
| Ежедневно | с 6:00 суток, следующих за сутками данных (Task 365) | данные за предыдущие сутки цикла |
| Еженедельно | календарная неделя данных (пн–вс) прошла | данные этой недели |
| Ежемесячно | календарный месяц данных прошёл | данные этого месяца |

- Границы: понедельник 00:00 (неделя), 1-е число 00:00 (месяц); нет данных — красный.
- **Укрепление распознавания периода** (регэкспы вместо `indexOf`):
  - недельная ветка `/недел|еженед/` — ловит и сокращения «Еженед.»;
  - месячная ветка `/месяц|месяч|ежемес/` — ловит «Ежемес.» и «раз в месяц»
    (`indexOf('месяч')` не матчил «месяц» — такие периоды считались суточными
    и краснели по суткам — вероятная причина заявки).
- Основные периоды таблицы — полные слова («Ежедневно/Еженедельно/Ежемесячно»),
  для них поведение не изменилось.
