# DEPLOY-Task358 — гарантированная доставка показаний расходомеров (outbox)

**Репозиторий:** kip8test (мастер-версия; перенос в kip8 — отдельной записью)
**Дата:** 2026-09-10
**Тип:** только клиент (index.html + sw.js). Apps Script НЕ трогается. Десктопы: electron/main.js (см. ниже).

## Заявка

Пользователь вводит показания расходомера, нажимает «Сохранить», видит
обновлённую карточку (оптимистичный UI) и быстро переходит к карточке
следующего расходомера или сразу закрывает приложение — а введённые
значения не сохраняются на сервере.

## Причины (найдены в коде)

1. **Доставка отложена на 2 round-trip'а.** «Сохранить» → сначала
   `flowmeter.getRecentAllMeters` (клиентская валидация Task 200), и только
   потом `flowmeter.updateReading`. При плохой сети — секунды между кликом
   и фактической записью.
2. **Закрытие убивает fetch.** Обычный POST прерывается закрытием
   вкладки/приложения (Electron закрывался без перехвата). Показания
   терялись молча — карточка выглядела сохранённой.
3. **Затирание soft-confirm payload.** При «подозрительных» показаниях
   модалка подтверждения откладывала отправку (`_pendingApiPayload` — одна
   переменная): быстрый переход к следующему расходомеру затирал payload
   новым вводом — показание терялось бесследно.
4. **Ретрай только 1 раз (1 с).** Затянувшаяся сетевая проблема = потеря.

## Решение — write-ahead журнал (outbox) в localStorage

Ключ `kip8_flow_outbox_v1` (через изоляцию — `kip8test:kip8_flow_outbox_v1`).

- Запись попадает в журнал **ДО** любых сетевых запросов (в т.ч. «расход
  за месяц», `updatePeriodReading`).
- Удаляется **только** после ответа сервера (доставлено/осознанно отвергнуто)
  либо явной отмены пользователя в модалке аномалий.
- Сеть/сессия истекла → запись остаётся; авто-флаш: init раздела,
  window online, вкладка снова видима, ретрай 15с→30с→60с.
- **Закрытие приложения:** `pagehide` → `navigator.sendBeacon` (text/plain —
  без preflight, ставится в очередь ДО выгрузки). Запись НЕ удаляется:
  следующий запуск сверяет с сервером — **дедуп** уберёт дубль (beacon дошёл)
  или отправит заново (не дошёл). Дедуп обязателен: архив пишется
  `appendRow` без проверки дублей.
- **Модалка аномалий** пере-показывается при флаше — подтверждение/отмена
  больше не теряются.
- **Честный UX:** баннер «⟳ Показаний ждут отправки: N — уйдут на сервер
  автоматически…», тост «Нет связи — показания сохранены на устройстве и
  будут отправлены автоматически», beforeunload-предупреждение при
  недоставленных данных (как Task 251 в шахматке).

### Десктоп (electron/main.js, отдельный коммит в *-desktop)

Перехват закрытия окна: `close` → preventDefault →
`executeJavaScript('FlowmeterData._outboxFlushBeacons()')` → destroy
(страховочный таймаут 1.2 с). `before-quit` поднимает флаг — авто-обновление
(`autoInstallOnAppQuit`) не ломается. Обратно совместимо: старый main.js +
новый index.html = pagehide-beacon всё равно уходит.

## Проверки после публикации

1. Ввести показания при выключенной сети → тост «…будут отправлены
   автоматически», баннер «⟳ Показаний ждут отправки: 1» в списке.
2. Включить сеть → через секунды тост «…отправлены: 1», баннер исчез,
   показания на карточке актуальны (проверить в Google Sheets).
3. Ввести показания и сразу закрыть приложение → при следующем открытии
   показания доезжают (beacon доехал — дедуп молча снимет; не доехал —
   отправится при флаше).
4. В «подозрительные» показания (аномалия) → уйти с карточки не отвечая
   на модалку → модалка пере-появится на следующем заходе в раздел.

## Отказоустойчивость

| Ситуация | Поведение |
|----------|-----------|
| Сеть пропала на вводе | Запись в outbox, тост, авто-доставка |
| Приложение закрыто в полёте запроса | beacon; дедуб на следующем запуске |
| beacon дошёл и повтор ушёл бы дублем | Дедуп по meters/archive — повтор не отправляется |
| Сервер отверг (окно правки 1 ч истекло) | Запись удалена, тост ошибки |
| Сессия истекла | Запись ждёт входа, уйдёт после (flush на init) |
| Старый сервер («Unknown action» период) | Запись ждёт обновления Apps Script |
| Гость (без входа) | Ничего не отправляется, записи ждут входа |
| Quota localStorage | Молча переживается, доставка продолжается |
