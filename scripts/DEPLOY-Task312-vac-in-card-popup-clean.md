1. **Кнопка «+ Отпуск» из тулбара → карточка сотрудника**:
   - кнопка `#wsVacBtn` и класс `.ws-addvac-btn` удалены из HTML и CSS
     (тёмная + светлая темы, правило высоты 34px Task 269 — без неё);
     `init()` больше не управляет её видимостью;
   - в `_renderEmpPopup` (блок «Отпуска · год», ПОСЛЕ списка периодов,
     ДО секции «Мероприятия») рендерится строка-действие
     **«+ Отпуск…»** (`.ws-popup-row.ws-popup-more.ws-emp-addvac` —
     стиль как у «+ Мероприятие…» в попапе ячейки) — **только
     редакторам** (`_canEdit`), зрителю строки нет;
   - новый метод `onEmpAddVacation(tabNo)`: закрыть карточку →
     `openVacationForm(tabNo)`;
   - `openVacationForm` принимает необязательный **таб. №**: сотрудник
     карточки выбирается в списке шторки ДО `onVacEmployeeChange()`,
     поэтому «часть» (первый свободный номер 1–3) и строка годового
     лимита 42 дн. (Task 310) сразу считаются для НУЖНОГО сотрудника;
     двойная защита `if (!this._canEdit) return` не снята;
   - шторка «Новый отпуск» (`#wsVacSheet`), лимит, блокировка
     превышения, подсказки ст. 112/120/125 ТК РФ — без изменений.

2. **Попап ячейки: коды мероприятий исключены из списка основных**:
   - в `_renderCellPopup` цикл статусов пропускает коды `_EVENT_CODES`
     (И/ОБ/ПЗ/ПР/*): мероприятия добавляются ТОЛЬКО через
     «+ Мероприятие…» (Task 303) и живут в ячейках
     бейджами-«иконками»; справка о событиях дня и кнопки ✎/✕
     (Task 309) — в секции «Мероприятия в этот день»;
   - день-событие без смены (сервер `generateMonth` пишет И/ОБ/ПЗ
     основным кодом): в попапе НЕ подсвечен строкой, событие видно
     в секции ниже — как и задумано;
   - select «Статус» в шите «Дополнительно…» (`_fillStatusSelect`):
     мероприятия не предлагаются к ВЫБОРУ, но ТЕКУЩЕЕ
     значение-мероприятие остаётся опцией (иначе шит «терял» бы
     статус ячейки).

3. **Строка «— выходной —» удалена из попапа ячейки**:
   - первый код «—» (которого нет в таблице «Коды_статусов») убран
     вместе с пунктирным свотчем; CSS-класс `.ws-popup-swatch-empty`
     удалён (мёртвое правило);
   - очистка ячейки («выходной») осталась в «Дополнительно…»:
     select со значением «— выходной —» + удаление записи;
     семантика авто/руч/локальной правки не менялась
     (`_applyCellStatus('')`, `__delete`).

4. **Цвет кода «.» (Плановый выходной день) — белый**:
   - **код цвета для листа «Коды_статусов»: `#FAF9F5`** — точный фон
     пустых ячеек с точкой в светлой теме (`--bg-primary`);
     пользователь заменяет значение в таблице сам;
   - fallback-набор в клиенте (`_loadStatusCodes`, офлайн/старый
     бэкенд) синхронизирован: `#CFD8DC` → `#FAF9F5`;
