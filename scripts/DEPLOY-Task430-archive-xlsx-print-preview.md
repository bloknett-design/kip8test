# Task 430 — кнопка «Сохранить архив» (Excel) + предпросмотр печати шахматки

**Заявка (kip8test):** «Я сделал все шаги в Apps Script. В общей
карте работников добавь кнопку сохранить архив, при нажатии на
которую весь архив по работникам должен сохраняться в формате
таблицы excel. При печати шахматки табеля, вначале должно
появляться диалоговое окно с предпросмотром и с возможностью
сохранения графика в файл».

## Что изменилось

**Клиент `index.html` (сервер Apps Script НЕ тронут: srvVer 427,
WorkSchedule.gs/Code.gs без изменений — серверные шаги Task 429
пользователем ВЫПОЛНЕНЫ и подтверждены):**

1. **Кнопка «Сохранить архив» в «Общей» вкладке карты работников
   (заявка):** вторая кнопка ряда действий шапки сводки (рядом с
   «Добавить работника», контейнер `.ws-wgen-actions`). Контурная
   (не акцентная — иерархия кнопок), с значком-дискетой; акцент
   берётся из переменной темы (тёмная — синий, светлая —
   оранжевый). **Доступна уровням edit И view** (фича выгрузки, как
   «Печать»; null/min страницу карточек не видят вовсе).

   Нажатие выгружает **весь архив по работникам** одним файлом
   Excel: книга из **ТРЁХ листов** (независимые разделы — по
   правилу Task 429 раздельно):
   - «Работники» — справочник (таб. №/ФИО/тип/смена/должность/
     группа допуска/дата приёма), по алфавиту;
   - «Инструктажи» — ВСЕ записи «Инструктажей» ВСЕХ лет
     (id/таб/ФИО/тип/тема/дата проведения/выполнено/просрочен/
     комментарий);
   - «Мероприятия» — ВСЕ записи «Мероприятий» ВСЕХ лет (id/таб/
     ФИО/тип/тема/период/длительность/комментарий).

   Данные — уже загруженные пулы карточки (`_INSTR_ALL`/`_EVENTS_ALL`
   Task 407/408 + годовой срез `_TRAININGS`; дедуп по семейству
   типа `i+id`/`e+id` — Task 427). Имя файла:
   `Архив_по_работникам_‹дата›.xlsx`. После выгрузки — тост с
   составом (N работников / инструктажей / мероприятий).

2. **XLSX-писатель — полностью клиентский, без библиотек** (PWA
   работает офлайн): собственный мини-генератор книги Excel —
   zip-контейнер (метод STORED, CRC32), листы с inline-строками,
   шапки жирным на синем (styles.xml), ширины колонок, закреплённая
   строка заголовков (freeze). Файл открывается Excel/
   LibreOffice/Google Sheets (проверено разбором zip в тестах и
   браузерной проверке).

3. **Диалог предпросмотра печати шахматки (заявка):** кнопка
   «Печать» тулбара больше не печатает сразу — сначала открывает
   модальный диалог `#wsPrintPrevModal`: белый «бумажный» лист
   (тот же HTML, что уйдёт на печать, в iframe со
   standalone-документом; CSS печатного листа переиспользуется из
   печатной медиа-секции — предпросмотр = печать), масштаб под
   ширину окна. Внизу — действия:
   - **«Печать»** — `window.print()` основного документа (печатная
     медиа-секция скрывает всё, кроме `#wsPrintSheet` — диалог
     тоже; диалог можно не закрывать);
   - **«Сохранить в файл»** — график сохраняется в загрузки
     браузера как standalone-HTML `График_работы_‹Месяц›_‹год›.html`
     (белый лист на подложке; печать файла из браузера даёт тот же
     A4 альбомный вид — @page вшит);
   - **«Отмена»** (также Esc и клик по затемнению).

   Диалог не открылся (нет DOM) — фолбэк прежнего поведения
   Task 341: печать сразу.

## Взаимодействие разделов (регресс)

Разделы инструктажей и мероприятий **НЕЗАВИСИМЫ** (Task 429): в
книге Excel — раздельные листы, записи читаются из СВОИХ пулов,
дедуп по раздельным id (Task 427). Серверная логика (автосоздание
повторных 419–423, мероприятия — только ручной ввод) не тронута и
покрыта тестами (4348/0).

## Самопроверка после деплоя

1. «Работники» → «Общая»: нажать «Сохранить архив» → в загрузках
   `Архив_по_работникам_‹дата›.xlsx`; открыть в Excel — три листа
   (Работники/Инструктажи/Мероприятия), шапки закреплены.
2. Шахматка → «Печать»: сначала диалог с предпросмотром листа
   (A4 альбомный, та же вёрстка, что на печать); кнопка «Печать»
   открывает системную печать; «Сохранить в файл» кладёт
   `График_работы_‹Месяц›_‹год›.html` в загрузки; Esc/«Отмена»
   закрывают диалог.
3. У просмотрщика (без прав правки) кнопка «Сохранить архив»
   видна и работает, «Добавить работника» — скрыта.
4. Мобильный: диалог предпросмотра — на весь экран; кнопки внизу.
