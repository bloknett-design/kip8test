## Что нужно сделать пользователю

**НИЧЕГО в Apps Script делать не нужно.** Изменился только фронтенд.

1. Открыть приложение в браузере.
2. **Ctrl+Shift+R** — подождать 3–5 секунд — **Ctrl+Shift+R** ещё раз
   (обновление Service Worker v533 → v534).
3. Открыть «Расходомеры хозрасчётные» → карточка «Хозрасчёт №1»:
   блока «Передано показаний (контроль)» над хронологией больше нет;
   кнопка «Изменить показатели» → chips «За сутки / За неделю / За
   месяц» работают как раньше.

Если после двух Ctrl+Shift+R блок всё ещё виден — закрыть вкладку
целиком и открыть заново (или F12 → Application → Service Workers →
Unregister, затем перезагрузка).
