# DEPLOY — Task 319 (только фронтенд)

## Что изменилось

**kip8test** — 4 правки «График работы» (файлы `index.html`, `sw.js`):

1. **Тултип «Обновить» не прячется под верхним баром.**
   Окно «данные от…» перенесено из `#page-work-schedule` в `<body>`
   (stacking-контекст `.page-content` (z 2) опускал его z 9450 ПОД
   sticky `.desktop-top-bar` (z 70) — окно физически пряталось за
   баром). Позиция «над кнопкой» теперь считается с учётом НИЗА
   бара: места не хватает — окно показывается ПОД кнопкой. На
   мобильном (бара нет) — прежнее поведение.

2. **Перекрестье шахматки.** Движение мыши по ячейкам дней
   выделяет СТРОКУ и СТОЛБЕЦ, пересекающиеся в ячейке под
   курсором (столбец — подсветка Task 316, строка — новый класс
   `ws-hover-row` на `<tr>`; пересечение насыщеннее). Снятие —
   уход курсора с ячеек (шапка/ФИО/вне сетки), смена месяца.
   Всем ролям, без мигания при переходах между ячейками.

3. **Тёмная тема — цвета шахматки дней как в светлой.** Пустые
   `#eef0f2`, пустые выходные `#f7d9e3`, текст кодов `#141413`
   (значения светлой темы), вся площадь ячеек слегка притенена
   поверхностным фильтром `filter: brightness(0.88)`. Статусные
   inline-цвета справочника — прежние (одинаковы в обеих темах).
   Шапка сетки и колонка ФИО остаются тёмными.

4. **Окно выбора кодов + окно «Мероприятия в этот день».**
   Название кода — 12px (было 13) и ПЕРЕНОСИТСЯ по строкам
   (длинные видны целиком; только окно кодов, окно мероприятий
   и карточка — прежний однострочный вид). ЗРИТЕЛЯМ («График
   работы — просмотр») клик по ячейке теперь открывает окно
   «Мероприятия в этот день» (справка, без кнопок ✎/✕); окно
   выбора кодов зрителю по-прежнему недоступно, тост «нет прав»
   удалён.

## Проверка после обновления

- Навести мышь на «Обновить»: окно «данные от…» видно ЦЕЛИКОМ,
  не заходит под верхний бар (на десктопе — под кнопкой).
- Вести мышь по шахматке: подсвечиваются строка и столбец
  «перекрестьем», ячейка под курсором — насыщеннее.
- Тёмная тема: шахматка дней светлая (слегка притенена), шапка и
  ФИО — тёмные; коды в ячейках читаются.
- Клик по ячейке (окно кодов): названия кодов мельче, длинное
  «Отпуск основной…» — в несколько строк.
- Роль без права правки («График работы — просмотр»): клик по
  ячейке открывает «Мероприятия в этот день», окно кодов не
  появляется, тоста «нет прав» нет.
