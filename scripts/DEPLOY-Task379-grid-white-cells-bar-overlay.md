  темы — #FFFFFF).
- **Тёмная тема НЕ тронута**: #eef0f2 + brightness(0.88)
  (Task 319) — как прежде; база var(--bg-primary) — как прежде.
- Праздники #f8e2e9 (Task 363), выходные (белые + красная

  поверх фона, работают как прежде.
- Итоги учёта Task 378 (#FFFFFF светлой / #eef0f2 тёмная, линии

### 2. Окна «Мероприятия»/«Нормы»: раскрытие = ОВЕРЛЕЙ вниз, бар не растёт
- **Было (Task 378):** клик по значку ставил инлайновую высоту
  scrollHeight — окно росло ВНУТРИ бара → .ws-bar-row / весь
  тулбар увеличивались в размере, сетка уезжала вниз.
- **Стало:** прирост высоты компенсируется ОТРИЦАТЕЛЬНЫМ
  margin-bottom = **95px − scrollHeight** (`_barExpSync` /
  `_barExpToggle` ставят и сбрасывают): в grid-строке бара
  (десктоп) и flex-колонке (мобайл) окно продолжает занимать
  РОВНО 95px — **габарит бара НЕ меняется**, ряды 2/3 и сетка
  под баром НЕ уезжают; низ окна смещается вниз ПОВЕРХ бара и
  шахматки (оверлей).
- CSS `.ws-events-panel.ws-bar-open, .ws-cal-panel.ws-bar-open`:
  **z-index 55** (над sticky-шапкой сетки z 2 и рядами бара, ПОД
  шапкой приложения z 60, шторкой итогов z 75, нижней навигацией
  z 100) + тень «парения» (тёмная rgba(0,0,0,0.38) / светлая
  0.22); фон окон уже непрозрачный — текст читается поверх сетки.
- `transition: height 0.18s, margin-bottom 0.18s` — СИНХРОННО:
  сумма height+margin всегда 95px, раскладка не дёргается ни на
  миг (плавное «выпадение» окна вниз).
- Поведение значка (Task 378) сохранено: шеврон в правом нижнем
  углу, opacity 0.45 не активен / 1 при hover/фокусе/раскрытии,
  поворот 180°, виден только при переполнении; авто-сворачивание
  при исчезновении переполнения теперь сбрасывает и маржу.
