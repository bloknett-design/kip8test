# Task 316 — Деплой: наведение/клик на дату шапки — подсветка всего столбца + фильтр окна мероприятий по дню

## Что менялось (ТОЛЬКО фронтенд — index.html, sw.js, tests/, scripts/)

**Суть:** дата в шапке шахматки стала интерактивной. Наведение курсора
подсвечивает ВЕСЬ столбец (шапка + ячейки тела — вид как у «сегодня»
Task 313, но мягче). Клик по дате ВЫБИРАЕТ день: столбец остаётся
выделенным (насыщеннее наведения), а окно мероприятий месяца
(#wsEventsPanel, Task 315) фильтруется по этому дню — показываются
записи, НАКРЫВАЮЩИЕ дату (дата_начала ≤ день ≤ дата_окончания,
границы включительно). Работает всем ролям (зритель тоже).

### 1) Наведение — подсветка столбца
- `th.ws-day-col` (все дни, все роли) получают `data-day` +
  `onmouseenter`/`onmouseleave` → `WorkSchedule._dayHover(d/null)`.
- th → класс `ws-hover-col` (linear-gradient поверх непрозрачного фона
  th + число акцентом — как «сегодня», тон мягче: тёмная
  rgba(74,143,199,0.20), светлая rgba(42,93,143,0.13)).
- ВСЕ `td[data-day]` столбца → `ws-hover` (inset-«заливка»
  `box-shadow: inset 0 0 0 999px rgba(74,143,199,0.16)` ПОВЕРХ
  inline-цветов статусов и планов; составные правила
  `.ws-hover.ws-source-manual` — рамка ручных д/н Task 309/310 не
  затирается; светлая тема — rgba(42,93,143,0.10)).
- Уход курсора — подсветка снимается. Классы ставятся ПРЯМО в DOM
  (`_dayColClass`) — без перерисовки сетки, без мигания; `_renderGrid`/
  `_renderCell` штампуют их из состояния (`_hoverDay`/`_selDay`) —
  подсветка и выбор ПЕРЕЖИВАЮТ перерисовку (правка, «Отменить»,
  «Обновить»).

### 2) Клик — выбор дня + фильтр окна мероприятий
- `onclick` даты → `WorkSchedule._daySelect(d)`:
  - th → `ws-sel-col`, td → `ws-sel` — НАСЫЩЕННЕЕ наведения (тёмная
    0.30/0.24, светлая 0.20/0.15);
  - `_renderMonthEventsPanel` перерисовывается С ФИЛЬТРОМ: записи,
    накрывающие дату; заголовок «Мероприятия · 05.09 · N» (день вместо
    месяца); пустой день — «нет мероприятий в этот день»; диапазоны
    строк остаются («02–05.09» видно при выборе 03.09);
  - повторный клик по той же дате — сброс (тоггл).
- СБРОС выбора:
  - клик по ЛЮБОЙ другой области — document-слушатель в `init` на
    CAPTURE-фазе (раньше inline-обработчиков, не зависит от
    stopPropagation попапов; клик по `th.ws-day-col` пропускается —
    его разбирает onclick даты). Клик по ячейке/тулбару/окнам/кнопкам/
    фону — снимает выбор;
  - Esc — сброс (общий keydown);
  - смена месяца/года — сброс (`onMonthChange` обнуляет
    `_hoverDay`/`_selDay` до loadGrid);
  - выбранный день ВНЕ открытого месяца (31 у 30-дневного) — охрана
    (полный месяц).
- `_daySelect(null)` — программный сброс (no-op без выбора).
- Курсор: `.ws-grid thead th.ws-day-col { cursor: pointer }` — дата
  кликабельна с одного взгляда (принцип Task 311).
- Hover/клик НЕ открывают попапы ячеек (попап — клик по ячейке, как
  прежде; при этом клик по ячейке снимает выбор дня — «другая
  область»).
