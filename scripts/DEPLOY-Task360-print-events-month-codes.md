# DEPLOY Task 360 — печать графика: список мероприятий месяца и коды этого месяца (один столбик)

**Дата:** 2026-09-10
**Заявка пользователя:** «В разделе Табель учёта рабочего времени, в отображении
распечатываемого графика, под графиком вначале должен отображаться список мероприятий
на текущий месяц в один столбик, а под списком, в один столбик перечень кодов с их
наименованием только которые есть в этом месяце.»

## Что изменилось (только клиент, index.html)

1. **Секция «Мероприятия · <месяц> <год> · N» под шахматкой.** Те же записи и та же
   выборка, что в окне «Мероприятия» тулбара (Task 313): записи листа «Инструктажи»,
   ПЕРЕСЕКАЮЩИЕ открытый месяц (`дата_начала..дата_окончания`, ISO-строки сравниваются
   лексикографически = хронологически — мероприятие 29.08–02.09 видно и в августе,
   и в сентябре), сортировка по дате начала, затем по таб. номеру. Каждое мероприятие
   — ОТДЕЛЬНОЙ строкой (один столбик): точка цвета кода (цвет — справочник
   «Коды_статусов»), диапазон дат («02.09», «02–05.09», «29.08–02.09»),
   «код · тема · ФИО» (сотрудника нет в справочнике — «таб. № N»; темы нет — имя кода).
   Пустой месяц — строка «нет мероприятий в этом месяце» (как в окне тулбара).
2. **Перечень кодов ТОЛЬКО этого месяца — под списком мероприятий.** Прежде легенда
   печатала весь справочник в одну строку. Теперь: коды собираются по ЭФФЕКТИВНЫМ
   записям ПЕЧАТАЕМЫХ строк (локальные правки учитываются, `__delete` исключается —
   как в сетке; «.» и коды мероприятий И/ОБ/ПЗ/ПР/* — тоже коды месяца: «.» виден в
   ячейках, коды мероприятий раскрываются в списке мероприятий выше), КАЖДЫЙ КОД
   ОТДЕЛЬНОЙ СТРОКОЙ (один столбик) с наименованием и цветом. Порядок — справочник
   `_STATUS_CODES` (единственный источник имён); легаси-код, удалённый из справочника,
   попадает в конец без цвета и имени (только код).
3. **CSS @media print:** новые правила `.wsp-mev` / `.wsp-mev-t` / `.wsp-mev-item`
   (display: block + page-break-inside: avoid — строка не рвётся между страницами) /
   `.wsp-mev-item i` (точка цвета, print-color-adjust: exact) / `.wsp-mev-date` /
   `.wsp-mev-none`; `.wsp-lg` — display: block (один код — одна строка, прежде —
   инлайн через margin-right/nowrap). Классы печати — wsp-mev-* (НЕ wsp-ev*: guard
   Task 343 «бейджи мероприятий в ячейках печати удалены» остаётся силён).
4. **Порядок секций листа:** шапка → шахматка → мероприятия месяца → коды месяца →
   сноска. Шахматка/колонки «Дни»/«Часы»/«Перераб.», шапка листа, сноска — НЕ тронуты
   (регресс 341/342/343 проверен).

## Серверная часть

НЕ требуется — Apps Script, Google Sheets, `.gs`-файлы не менялись. Данные берутся
из уже загруженных слоёв `_TRAININGS`/`_ENTRIES`/`_STATUS_CODES` (те же эндпоинты
`workSchedule.listTrainings`/`listEntries`/`getStatusCodes`).

## Проверка за 5 минут

1. Открыть «Табель учёта рабочего времени» → месяц с мероприятиями → «Печать»
   (или предпросмотр печати браузера).
2. ПОД шахматкой — «Мероприятия · <месяц> <год> · N»: каждая запись с новой строки:
   цветная точка, дата (или диапазон), «код · тема · ФИО». Мероприятие, начавшееся
   в прошлом месяце и закончившееся в текущем, — в списке с диапазоном «29.08–02.09».
3. Ниже — «Коды:»: каждый код с новой строки («Д — День (12-час)» …), только коды,
   реально стоящие в ячейках месяца (включая «.»); НЕиспользуемые коды справочника —
   отсутствуют.
4. Пустой месяц по мероприятиям — строка «нет мероприятий в этом месяце».
5. Вид табеля «сменный»/«дневной» — перечень кодов соответствует ПЕЧАТАЕМЫМ строкам
   (коды сотрудников скрытого вида в перечень не попадают).
