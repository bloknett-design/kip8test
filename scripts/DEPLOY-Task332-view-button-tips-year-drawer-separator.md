## Заявка
«Сделай подсказку кнопки включения подсветки строк и столбцов (как в
других кнопках в баре), слева от неё добавь новую кнопку переключения
вида 1-полный (доступны все элементы), 2-сменный (не доступны шахматка
дневных сотрудников и шторка), 3-дневной (не доступны шахматка сменных
сотрудников и шторка), (так же с подсказкой), для роли КИП ИОС дежурный,
доступен только вид 2-сменный. В шторке на год убери кнопку "Обновить"
и столбец сотрудников. В шахматке табеля сделай разделительную полосу
между столбцом сотрудников и ячейками шахматки такой же как левая полоса
в шторке (полоса 2px #4a8fc7/светлая #6e8ba4 — точно как разделитель
сменных/дневных в шахматке).»

## Что изменилось (только клиент — index.html + sw.js)
1. **Подсказка значка подсветки #wsCrossTip** — информационное окно
   формата «Обновить»/«Сформировать» (Task 317/328): заголовок +
   описание + ЖИВОЕ состояние («Сейчас подсветка включена/выключена» —
   #wsCrossTipState обновляется перед показом и сразу после
   toggleCross). Показ при наведении/фокусе, скрытие — уходом курсора/
   кликом/прокруткой; окно в <body> (Task 319), кликам не мешает.
   Нативного title НЕТ.
2. **Кнопка вида #wsViewBtn** — САМАЯ ЛЕВАЯ ряда 3 (порядок: вид →
   подсветка → «Сформировать» → «Сохранить» → «Отменить»). Класс
   ws-cross-btn (размер/вид = значок подсветки) + ws-view-btn.
   Три иконки #wsViewIconFull/Shift/Day: 4 полосы двумя группами
   (верх — сменные, низ — дневные, зазор между группами), у «чужой»
   группы opacity 0.25 — текущий вид виден сразу. Переключение по
   кругу полный → сменный → дневной → полный (cycleView), сохранение
   kip8_ws_view_v1, тосты, aria-label с текущим видом. Подсказка
   #wsViewTip — тот же формат (заголовок «Вид табеля: <вид>», описание
   трёх видов; для запертой роли — «доступен только сменный»).
3. **Применение вида (_applyView/_viewEmployees)**: полный — все
   элементы; сменный — строки сетки только «тип»=сменный, кнопка
   «Итоги учёта» скрыта, открытая шторка закрывается; дневной —
   только дневные. _EMPLOYEES не трогаем — фильтр только отрисовки.
   Гейты: toggleTotals/setTotalsTab не открывают шторку из
   неполного вида (толерантно к отсутствию _view — VM-моки/легаси).
   Пустой вид — «Сотрудники вида «…» отсутствуют.»
4. **Роль «КИП ИОС дежурный»** — вид ЗАПЕРТ на «сменный»
   (_viewLocked): _initView игнорирует сохранённый выбор, клики дают
   тост-пояснение, кнопка приглушена (.ws-view-locked opacity 0.6).
   Хук WorkSchedule._onRoleUpdate из KipAuth._applyRoleToUI — роль
   может прийти ПОЗЖЕ init (медленный путь bootstrap/фоновая
   проверка): обновляет _canEdit/«Сформировать» и замок; идемпотентно.
5. **Шторка «Год»**: кнопка «Обновить» шапки УДАЛЕНА (HTML + CSS +
   логика; метод reloadTotals остался API) — годовые данные обновляет
   кнопка «Обновить» тулбара (loadGrid(true) сбрасывает _YEAR_DATA,
   Task 321; открытая вкладка года перезагружается автоматически —
   проверено браузером). ⚠-тексты переадресованы на кнопку тулбара.
   Столбец «Сотрудник» и архивные строки года УДАЛЕНЫ: строки года =
   строки сетки (только активные, как вкладка «Месяц»; имена — в
   стик-колонке ФИО шахматки), шапка начинается с «янв»; CSS-бейдж
   .ws-tt-arch удалён. Годовой справочник (md.employees, вкл. архив)
   остаётся источником ТИПОВ для переработки д/н.
6. **Разделительная полоса шахматки**: `border-right: 2px solid
   #4a8fc7` (светлая #6e8ba4) на th/td.ws-emp-col — точно как левая
   полоса шторки (.ws-tt-edge, Task 331) и разделитель сменных/дневных
   (tr.ws-group-first td). Полоса на sticky-колонке — по всей высоте
   (шапка и тело), при горизонтальной прокрутке остаётся на границе.
