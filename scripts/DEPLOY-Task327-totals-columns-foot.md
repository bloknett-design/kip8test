# Task 327 — Итоги учёта: столбцы по заявке + бордюрчик + вкладки при открытии (kip8test)

## Заявка пользователя

«В шторке итогов учёта убери строку общего количества, в таблице оставь
основные столбцы в такой последовательности Явки, Часы, Переработка, и
дополнительные скрытые столбцы Отгул, Больничный, Отпуск, Уч. отпуск,
Прогул, День, Ночь, Прочие, столбец Всего убери. Столбцы в шторке итогов
выравни по ширине, текст заголовков сделай в две строки для компактности,
при необходимости. Внизу шторки сделай такой же бордюрчик как в шахматке
табеля. Кнопки "Месяц" и "Год" должны появляться при открытии шторки
итогов учёта.»

## Что сделано (только фронтенд, сервер/листы/Apps Script НЕ тронуты)

1. **Строка общего количества УБРАНА**: tfoot «Итого по подразделению»
   больше не рендерится в таблицах месяца И года; CSS-правила
   .ws-tt-total/tfoot удалены; резерв высоты в _fitGrid убран
   (бюджет строк = область − шапка − полоса); низ таблицы закрывает
   бордюрчик.
2. **Основные столбцы: Явки, Часы, Переработка** (порядок заявки).
   Рендер переведён на массив колонок (cols) —
   _renderTotalsMonth строит шапку/строки циклом.
3. **Дополнительные СКРЫТЫЕ столбцы** — Отгул (ОВ), Больничный (Б),
   Отпуск (ОТ), Уч. отпуск (У), Прогул (ПР), День (Д), Ночь (Н),
   Прочие — кнопка **«Ещё»/«Меньше»** в шапке шторки
   (#wsTtMore, toggleTotalsExtra, состояние _totalsExtra; видна
   только на вкладке «Месяц»). Развёрнутый вид: min-width
   cols×64px → горизонтальная прокрутка ползунком шторки.
4. **Столбец «Всего» УДАЛЁН** (и из месяца, и потенциально из
   развёрнутого вида — колонки задаются списком).
5. **Столбцы РАВНОЙ ширины**: месячная таблица —
   `table-layout: fixed` (столбцы без ширины делят остаток поровну);
   колонка «Сотрудник» (мобайл) — 42% + эллипсис; год — прежняя
   авто-раскладка (12 колонок «дни/часы»).
6. **Заголовки в ДВЕ строки при необходимости**: th — white-space:
   normal + overflow-wrap/word-break + hyphens: auto + центрирование
   (Task 324 «одной строкой» свёрнут — узкие равные столбцы требуют
   переноса); год — заголовки-месяцы по-прежнему одной строкой.
7. **БОРДЮРЧИК внизу шторки как в шахматке**: .ws-tt-foot — тот же
   стальной bevel, что .ws-grid-foot (5px, #35648f/#85b7dc, светлая
   #b3c2ce), после #wsTtBody (вне скролл-зоны, у низа панели).
8. **«Месяц»/«Год» появляются при открытии шторки**: обе вкладки
   скрыты (hidden) до открытия — _updateTtTabsVisible показывает их
   в toggleTotals (открыла → появились, закрыла → убрались);
   .ws-tt-tab[hidden] гасит кнопку; клик по вкладке закрытой шторки
   по-прежнему открывает её (setTotalsTab).
   Сопутствующее: _updateTtMoreBtn (кнопка «Ещё» — только месяц,
   синхронна шторке); _updateTtHead учитывает «Ещё» (шапка не
   сжимается, пока кнопка видна — выравнивание строк по сетке
   сохранено); setTotalsTab обновляет «Ещё».
