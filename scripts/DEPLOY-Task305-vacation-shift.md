# Task 305 — Деплой «Отпуск в приоритете, плановая смена — бейджем»

## Что меняется

**Сценарий (заявка пользователя):** у работников «сменный» при
автоматическом формировании шахматки по таблицам «Дни_цикла» и
«Отпуска» код отпуска отображается В ПРИОРИТЕТЕ (основной код
ячейки — так было и раньше), а плановые смены «день» (Д) и «ночь» (Н)
— маленьким бейджем в правом НИЖНЕМ углу ячейки, в формате
мероприятия (как И/ОБ/ПЗ из Task 303).

Пример из живой таблицы (сентябрь 2026): Хадасевич А. С. (таб 2741,
сменный, шаблон 1 «Д→Н→3 вых.») в отпуске 01–21.09. Дни 03, 04, 08,
09, 13, 14, 18, 19 сентября по циклу — смены Д/Н, но запись — «ОТ».
Теперь в этих ячейках видно «ОТ» + бейдж «Д» или «Н» (какая смена
«пропала» под отпуском); в цикловых выходных (05–07, 10–12, 15–17) —
только «ОТ», бейджа нет.

вычисляется при отрисовке, в таблицу не пишется, «Сформировать»
не требуется.

## Клиент (index.html, SW v544)

- `_plannedShiftAt(дата, сотрудник)` — плановый код дня по циклу
  (тот же алгоритм, что шаг 3 `generateMonth`: день цикла =
  ((дней от старта % цикл) + цикл) % цикл + 1 → «Дни_цикла»).
- Бейдж: `.ws-ev-badge.ws-ev-shift` — тот же формат мероприятия
  (Task 303): цвет — из справочника кодов, тёмный текст, правый
  нижний угол, 9px. Показывается на днях, чей основной код — отпуск
  («ОТ»/«У» — запись или ручная правка) ИЛИ пустая ячейка внутри
  периода листа «Отпуска» (план до «Сформировать» — пунктирная
  рамка + сплошной бейдж).
- НЕ показывается: сменные дни (код уже основной), больничный/отгул/
  прогул (не семейство отпусков), цикловые выходные, сотрудники без
  шаблона ротации, при сбое загрузки шаблонов (тихая деградация).
- Тултип ячейки: + строка «по циклу (Дни_цикла): <полное название
  смены>» (например, «по циклу (Дни_цикла): День, плановая дневная
  12-часовая смена (7:30–19:30)»).
- `loadGrid` теперь подгружает и шаблоны ротации (`getPatterns`)
  вместе с записями/мероприятиями/отпусками — бейджи всегда по
  свежим данным цикла; сбой запроса не ломает сетку.
- Работает для всех сотрудников с шаблоном ротации: сменные (Д/Н)
  и дневные (Д8/Д7,2) — семантика единая («какая смена была бы по
  циклу»). Если нужно ограничить только «сменным» по типу —
  скажите, добавим фильтр (одна строка).
