# DEPLOY Task 362 — печать графика: мероприятия только печатаемого вида, коды мероприятий в перечне кодов

**Дата:** 2026-09-10
**Заявка пользователя:** «при печати сменного графика, мероприятия должны быть указанны только для
сменных сотрудников, так же при печати графика дневного персонала. и не отобразилось наименование
кода проверки знаний ПЗ, хотя он есть в мероприятиях у дневного сотрудника.»

## Что изменилось (только клиент, index.html)

1. **Список «Мероприятия · месяц · N» под шахматкой — по виду табеля.** В видах «сменный»/
   «дневной» печатаются ТОЛЬКО мероприятия сотрудников печатаемых строк (`viewTabs` из
   `viewEmps` — те же строки, что в шахматке: фильтр вида + скрытие «Мастер КИПиА» у уровня
   min), ровно те, чьи бейджи напечатаны в ячейках. Записи «Инструктажей» чужого вида
   (вкл. сотрудников не из справочника) — НЕ попадают. **Полный вид — без фильтра**,
   как в окне «Мероприятия» тулбара (регресс Task 360: все записи месяца, у удалённых —
   фолбэк «таб. №N»). Счётчик «· N» показывает отфильтрованное количество.
2. **Перечень «Коды:» — пополняется кодами мероприятий из списка месяца.** Прежде
   `usedCodes` собирался только по эффективным записям СЕТКИ печатаемых строк: у дневного
   персонала мероприятие «проверка знаний» живёт только в листе «Инструктажи» (записи
   сетки нет), бейдж в ячейке печати ставится, а наименование «ПЗ — Проверка знаний»
   в перечне НЕ печаталось — хотя сноска листа ссылается на перечень («коды и цвета —
   в перечне выше»). Теперь коды И/ОБ/ПЗ/ПР/* из отфильтрованного списка мероприятий
   тоже помечаются в `usedCodes`: перечень объясняет ВСЕ напечатанные значки. Коды
   статус-мероприятий сетки по-прежнему учитываются циклом строк (Task 360). Код
   мероприятия вне месяца / неизвестный тип записи — ничего не добавляет.
3. **НЕ тронуты:** выборка по пересечению с месяцем и сортировка списка (Task 360),
   формат строк (точка цвета · диапазон дат · «код · тема · ФИО»), заглушка пустого
   месяца, порядок перечня (справочник → легаси-коды в конце), ширина колонки
   «Сотрудник» и шрифты (Task 361), бейджи в ячейках (Task 361), итоговая строка
   по-прежнему ОТСУТСТВУЕТ (Task 343), шапка «вид табеля: …» (Task 341).

## Проверка за 5 минут

1. Открыть «Табель учёта рабочего времени», переключить вид кнопкой «Вид» на «сменный» →
   «Печать»: в списке под таблицей — мероприятия ТОЛЬКО сменных сотрудников (дневных нет);
   в перечне кодов нет кодов мероприятий дневных.
2. Переключить вид на «дневной» → «Печать»: в списке — мероприятия ТОЛЬКО дневного
   персонала; у дневного сотрудника с «проверкой знаний» в перечне кодов появилась
   строка «ПЗ — Проверка знаний» (цвет точки — как у бейджа в ячейке).
3. Полный вид → «Печать»: все записи месяца (как в окне «Мероприятия» тулбара), включая
   мероприятия уволенных (фолбэк «таб. №N») — регресс Task 360.
4. Счётчик в заголовке секции «Мероприятия · месяц · N» равен числу строк под ним.
