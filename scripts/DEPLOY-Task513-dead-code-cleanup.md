## ⚠️ Почему это важно для триггеров

При слиянии GAS-файлов одноимённые функции перекрывают друг друга (последняя по
порядку загрузки — как правило, алфавитному: `Utils.gs` позже `Code.gs`). Пока копия
жила в `Utils.gs`, запуск `setupTriggers()` из редактора мог выполниться по ОПАСНОЙ
ветке — с удалением ВСЕХ триггеров проекта. После замены `Utils.gs` останется
единственный канон в `Code.gs`.
