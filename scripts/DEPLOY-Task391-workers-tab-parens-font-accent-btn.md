# DEPLOY — Task 391 (kip8test)

## Что вошло (заявка)

«Общая» вкладка раздела Табель учёта рабочего времени / Работники:

1. **Строки шапки — формат В СКОБКАХ** (переделка):
   - `Работников по штату 14 (2 мастера, 7 дневных, 5 сменных).`
   - ниже строчкой `Работников на текущий момент (N) ((N) мастера, (N) дневных, (N) сменных).`
     — N = АВТОПОДСЧЁТ ПО КАТЕГОРИЯМ (мастера — по должности «Мастер
     КИПиА» через `_isMasterKipia`, дневные/сменные — по типу БЕЗ
     мастеров); ведущее число в скобках — СУММА категорий (сходится
     с разбивкой в той же строке); запятые вместо точек с запятой.
2. **Шрифт строк — немного больше и ярче**: `.ws-wgen-staff` и
   `.ws-workers-count` — 14px / font-weight 600 / opacity 0.95
   (было 12px / 0.75).
3. **Кнопка «Добавить работника» — В СТИЛЕ САЙТА (акцентная)**:
   `background: var(--accent-blue, #4a8fc7)` + белый текст →
   тёмная тема — СИНИЙ `#4a8fc7`, светлая — ОРАНЖЕВЫЙ `#C6613F`
   (акцент сайта); hover/active — фильтром яркости (1.12 / 0.9);
   нейтральные рамки/фоны и светлые оверрайды кнопки удалены.

Инварианты прежних задач сохранены: id `wsWorkersAddBtn`, гейт
`_canEdit` (кнопка только у редакторов), выделенная шапка
`.ws-wgen-head` (#1E2B42 / #E4E0D3), примыкание ярлыков к окну
вкладок, порядок строк (штат — первой строчкой), пустой список —
`(0) (0 мастеров, 0 дневных, 0 сменных)` + подсказка.
