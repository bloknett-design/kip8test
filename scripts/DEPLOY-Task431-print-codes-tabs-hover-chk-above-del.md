# Task 431 — печать (коды рядом с мероприятиями) + тёмные ярлыки + hover зебры + галочка над удалением

**Заявка (kip8test):** «При печати графика работы, список кодов
расположи справа от списка мероприятий на расстоянии 10px, сейчас
между ними очень большое расстояние, посмотри и исправь, а нижнюю
строку с примечаниями расположи под ними. В тёмной теме фон ярлыков
работников сделай как фон в блоках карт работников. В блоке
Повторные инструктажи и периодическая проверка знаний, при
наведении указателя мыши на строку зебры, она меняет цвет фона,
убери этот эффект, и кнопку отметки выполнения расположи над
кнопкой удалить».

## Что изменилось

**Клиент `index.html` (сервер Apps Script НЕ тронут — srvVer 427,
WorkSchedule.gs/Code.gs без изменений):**

1. **Печать — коды в 10px справа от списка мероприятий.**
   Столбик мероприятий `.wsp-mev` больше НЕ растягивается на всю
   свободную ширину листа (`flex: 1 1 auto` → `0 1 auto` — именно
   растяжка уводила столбик кодов к правому краю листа и создавала
   «очень большое расстояние»). Колонка сжимается до самого широкого
   текста записи, столбик «Коды:» встаёт РЯДОМ с текстом мероприятий
   (зазор — прежний `gap: 10px` обёртки `.wsp-bottom`, Task 375),
   а не у правого края. Сноска `wsp-foot`
   («* — сокращённый предпраздничный рабочий день; …») — ПОД обоими
   столбиками, на всю ширину листа (как и прежде). Работает и в
   диалоге предпросмотра печати (Task 430), и при прямой печати.

2. **Тёмная тема: фон ярлыков работников = фон блоков карт.**
   Тёплый тон ярлыков Task 390 заменён семейством фона блоков карты
   `.ws-wcard` (#243349, Task 395):
   - неактивный ярлык — **#243349** (точно фон блока карты);
   - hover — **#2A3A53** (шаг светлее);
   - активный — **#31445F** (самый светлый, акцентная планка слева
     и жирный текст живут).
   Светлая тема — БЕЗ изменений (#E4E0D3/#DBD6C8/var(--bg-tertiary)).
   Мобильная лента ярлыков наследует те же цвета.

3. **Блок «Повторные инструктажи…»: hover строки НЕ меняет фон.**
   Подсветка строки при наведении снята в ОБЕИХ темах — правила
   колонки инструктажей `.ws-wcol-instr` (в ней живёт только окно
   блока):
   - НЕзебра-строки — прозрачный hover (в светлой теме был виден
     синий `rgba(42,93,143,0.12)` от общего правила
     `[data-theme="light"] .ws-popup-row:hover` — именно его и видел
     пользователь);
   - зебра-строки — держат свой статичный оттенок (не
     сбрасываются в прозрачный).
   Зона — только блок инструктажей: строки мероприятий/отпусков/СИЗ
   и попапы шахматки НЕ тронуты.

4. **Кнопка отметки выполнения — НАД кнопкой удаления.** Конец
   строки записи инструктажа в карточке — вертикальная колонка
   `.ws-act-col` (inline-flex column, gap 2px): галочка ✓ сверху,
   кнопка удаления ✕ снизу. Кнопка правки ✎ — левее колонки,
   горизонтально (как прежде по порядку следования). У зрителей
   (уровень view) — колонка с одной некликабельной галочкой
   состояния (только для выполненных записей). Записи без id — без
   колонки. Попап ячейки шахматки — прежний горизонтальный порядок
   ✎/✕ (галочки в попапе нет — Task 418). Интерактивность галочки
   (toggleTrainingDone) и автосоздание повторных инструктажей —
   БЕЗ изменений.
