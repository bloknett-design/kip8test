## Что изменилось (заявка пользователя)

> «В шахматке должен немного подсвечиваться фон сегодняшней даты. При
> нажатии на ячейку в шахматке, помимо окна с кодами, должно появляться

> цвета, кода и названием, а в окне с кодами убери строку "Мероприятия
> в этот день", теперь этот функционал будет в окне выше, которое как
> раз можно назвать "Мероприятия в этот день"».

1. **Подсветка сегодняшней даты в шахматке**:
   - `_renderGrid` кэширует ISO сегодняшней даты в `this._todayIso`
     (пересчитывается на каждой отрисовке; ячейки не зовут `new Date()`
     по сто раз);
   - шапка: колонка сегодняшней даты — класс `ws-today-col`
     (`.ws-grid thead th.ws-day-col.ws-today-col`): лёгкий градиент
     ПОВЕРХ непрозрачного фона th (строка sticky обязана оставаться
     непрозрачной) + число даты акцентным цветом; правило стоит ПОСЛЕ
     `.ws-holiday` — приоритет и на «сегодня-выходном»;
   - ячейки тела: `_renderCell` даёт класс `ws-today` ячейкам столбца
     (`isoDate === this._todayIso`); тонировка — inset-«заливка»
     `box-shadow: inset 0 0 0 999px rgba(74,143,199,0.16)`: рисуется
     ПОВЕРХ inline-цветов статусов (CSS-фон их не перекрывает) и ПОД
     текстом; псевдоэлементы не заняты (::before — рамка ручных д/н
     Task 309, ::after — точка переработки Task 250);
   - совпадение «сегодня + ручная запись»: составное правило
     `.ws-today.ws-source-manual` — обе inset-тени (заливка дня +
     рамка ручной записи 1.5px) в одном box-shadow;
   - светлая тема: шапка `rgba(42,93,143,0.13)`, ячейки
     `rgba(42,93,143,0.10)` — мягче тёмной; подсветка видна и зрителям
     (не требует прав).

2. **Отдельное окно «Мероприятия в этот день» НАД окном кодов**:
   - НОВЫЙ контейнер `#wsEventsPopup` (`.ws-cell-popup.ws-events-popup`,
     `role="dialog"`) в HTML после `#wsCellPopup`: база — .ws-cell-popup
     (фон/рамка/скролл), своё — max-height 300px и z-index 9402
     (окно кодов — 9401, кловер — 9400): при тесном вьюпорте окно
     мероприятий остаётся сверху, порядок «над окном кодов» не
     нарушается;
   - НОВЫЙ метод `_renderEventsPopup(isoDate, tabNo)`: заголовок
     «Мероприятия в этот день» + подстрока «дата · ФИО» (контекст, если
     вьюпорт развёл окна), строки мероприятий — свотч ЦВЕТА + КОД +
     НАЗВАНИЕ (тема из листа «Инструктажи», иначе название кода),
     кнопки ✎/✕ — только редакторам (Task 309, stopPropagation);
     пустой день — курсив «нет мероприятий» (окно открывается ВСЕГДА
     вместе с окном кодов — поведение предсказуемо);
   - `_renderCellPopup`: секция «Мероприятия в этот день» УДАЛЕНА
     (строки-события и `_eventsAt` из окна кодов ушли); «+ Мероприятие…»
     и «Дополнительно…» — живы в окне кодов;
   - `_openCellPopup`: рендерит ОБА окна; окно мероприятий
     позиционируется СТРОГО НАД окном кодов — левые края выровнены,
     зазор 8px (`eTop = top - eh - 8`); не влезает сверху — окно кодов
     сдвигается вниз (низ прижимается к краю вьюпорта, окна НЕ меняются
     местами); совсем тесный вьюпорт — окно мероприятий прижимается
     к верху (каскад z-index выше);
   - `closeCellPopup` закрывает ОБА окна (один жизненный цикл: кловер,
     Esc, выбор статуса, «+ Мероприятие…», «Дополнительно…»,
     editTraining/deleteTraining, клик по ФИО сотрудника);
   - слой событий прежний: `_eventsAt` (лист «Инструктажи»), сервер и
     generateMonth НЕ менялись.
