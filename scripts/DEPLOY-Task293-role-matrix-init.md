# DEPLOY-Task293 — Инициализация матрицы доступа в KIP8_Access

**Версия скрипта: v2** (исправлена ошибка v1 — `setItalic()` не существует
в Apps Script Range API, заменён на `setFontStyle('italic')`; добавлена
функция `roleMatrixCleanup()`; распознавание частичной инициализации).

**Что это**: одноразовый запуск скрипта `RoleMatrixInit.gs`, который создаёт
в таблице **KIP8_Access** 3 новых листа системы доступа (matrix, permissions,
roles). Приложение (PWA / Apps Script Web App) на этом этапе **не меняется и
не передеплоивается** — новая таблица станет источником истины для системы
доступа на следующих этапах (Task 294+: RoleMatrix.gs чтение, клиент,
вкладка админ-панели).

**Безопасность**: существующие листы (users, sessions, otp_codes, audit_log,
config) не затрагиваются. Повторный запуск ничего не изменяет (идемпотентно).
Расширение Web App (деплой AKfycbyt…) трогать НЕ нужно.

## Шаги запуска (5 минут)

1. Открыть таблицу **KIP8_Access**
   (docs.google.com/spreadsheets/d/1TmmNZLUArWH38F6NX0gMGar8LMNMQomm_FaGZv9osyk).
2. Меню: **Расширения → Apps Script** — откроется редактор проекта,
   привязанного к этой таблице (тот же, что развёрнут как Web App).
3. На панели файлов слева: **+ → Скрипт (Файл)** → назвать
   `RoleMatrixInit` → в открывшийся файл вставить всё содержимое
   `RoleMatrixInit.gs` (из download/kip8test/).
4. **Ctrl+S** (сохранить).
5. Сверху в выпадающем списке функций выбрать **roleMatrixInit** →
   **Выполнить** (Run).
   - Первый запуск попросит авторизацию (Review permissions → выбрать
     аккаунт → Разрешить) — это доступ скрипта к вашей же таблице,
     безопасно.
6. Дождаться завершения. В журнале выполнения (Execution log) должно быть:
   `Готово. Созданы листы: matrix, permissions, roles. Прав: 13, ролей: 12.`
7. Перейти в таблицу и проверить 3 новых листа (вкладки внизу):
   - **matrix** — «роль × право», чекбоксы-галочки;
   - **permissions** — справочник 13 прав с описаниями;
   - **roles** — справочник 12 ролей.
8. Файл `RoleMatrixInit.gs` в проекте Apps Script можно оставить (он не
   участвует в обработке запросов) или удалить — на работу Web App не влияет.

## Если уже запускали v1 (упал с ошибкой setItalic)

v1 успел частично создать лист `matrix` (permissions/roles не создались).
Восстановление:

1. Обновить содержимое файла RoleMatrixInit в Apps Script на код v2
   (Ctrl+A → вставить новый код → Ctrl+S).
2. В выпадающем списке функций выбрать **roleMatrixCleanup** → Выполнить —
   удалит недосозданные листы.
3. Выбрать **roleMatrixInit** → Выполнить.

## Проверка результата

- В листе **matrix**: 12 ролей-строк, 13 колонок-прав с галочками,
  роли «Запрет / Общий доступ / Админ» обведены золотой рамкой
  (системные — защищены от удаления).
- Названия ролей в колонке B листа matrix и в листе roles **точно**
  совпадают со значениями role в листе users (связка по названию).
- Технические строки (1–5) и колонки A–B при попытке редактирования
  показывают предупреждение (мягкая защита warning-only).
