# DEPLOY Task 290 — счётчик «За неделю»: последняя ПОЛНАЯ неделя (т + Гкал + период)

**Дата:** 2026-09-01
**Задача:** По заявке пользователя — «За неделю: 53,60 т» показывал
показания одних суток (31.08.2026), а не недели. Счётчик переделан:
складываются показания, переданные за КАЖДЫЕ сутки последней ПОЛНОЙ
календарной недели (пн–вс); по тому же принципу суммируются Гкал;
период дней недели подписан в счётчике; в начале каждой недели
показания меняются на данные новой закрывшейся полной недели — БЕЗ
сохранения в архив.

---

## Что изменилось

| Что | Было (Task 289) | Стало (Task 290) |
|-----|-----------------|-------------------|
| Какая неделя считается | Текущая (пн–вс, включая сегодня) | **Последняя ПОЛНАЯ** — пн–вс, завершившаяся в прошлое воскресенье |
| Почему было неверно | В начале недели текущая неделя содержит 1–2 суток → счётчик показывал свежие сутки (53,60 т за 31.08), а не сумму недели | Суммируются показания, переданные за **каждые сутки** полной недели |
| Гкал | Не считались | **Суммируются по тому же принципу** (по последней записи каждой даты; показывается, если хоть за одни сутки недели введена) |
| Период недели | Не подписан | **«За неделю 24.08–30.08.2026: 345,60 т · 1,260 Гкал»** (через границу года — «28.12.2026–03.01.2027») |
| Смена недели | — | **Ровно в понедельник** счётчик переходит на только что закрывшуюся неделю — автоматически, по дате «сегодня» |
| Архив | Не пишется | **По-прежнему не пишется** — чистый рендер из суточных записей |
| Правки за тот же день | По последней записи даты | Без изменений (не задваиваются; Гкал — из той же свежей записи) |
| CSS | `.flow-week-counter` — nowrap | **Перенос**: `.flow-archive-title` flex-wrap + счётчик white-space:normal/text-align:right — на 375px длинный счётчик переносится, не вылезая за экран; на широких — в одной строке справа от «Хронология показаний» |
| Сервер (Apps Script) | — | **НЕ менялся** — делать ничего не нужно |
| Ввод «за сутки» / «за месяц» | Сутки → updateReading; месяц → updatePeriodReading (архив) | **Без изменений** |
| Service Worker | kipia-test-v535 | **kipia-test-v536** |

## Что нужно сделать пользователю

**Только фронтенд — 1 шаг:**

1. Открыть приложение в браузере.
2. **Ctrl+Shift+R** — подождать 3–5 секунд — **Ctrl+Shift+R** ещё раз
   (обновление Service Worker v535 → v536).
3. Открыть «Расходомеры хозрасчётные» → карточка «Хозрасчёт №1»:
   - в строке «ХРОНОЛОГИЯ ПОКАЗАНИЙ» справа —
     «За неделю 24.08–30.08.2026: … т · … Гкал» — сумма показаний
     всех суток закрывшейся недели с подписью периода;
   - в понедельник (начало новой недели) счётчик сам покажет данные
     только что закрывшейся недели;
   - если за полную неделю нет суточных записей — «За неделю
     24.08–30.08.2026: —».

Если после двух Ctrl+Shift+R изменения не видны — закрыть вкладку
целиком и открыть заново (или F12 → Application → Service Workers →
Unregister, затем перезагрузка).
