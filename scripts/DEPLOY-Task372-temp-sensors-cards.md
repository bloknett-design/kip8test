## Что изменилось

### 1. Страница выбора = карточки (`#page-temp-sensors`)
- Было: conv-3col страница с формой (select «Тип датчика» → «Тип ТС»/«Тип термопары» + диапазон + шаг + «Рассчитать»).
- Стало: страница карточек (`.ts-page`): две группы с заголовками-бейджами —
  «ТС Термометры сопротивления · ГОСТ 6651-2009» (8 карточек: 50М/100М Cu α=0,00428 и α=0,00426, 50П/100П, Pt100/Pt1000 IEC)
  и «ТП Термопары · ГОСТ Р 8.585-2001» (8 карточек: ТХА K, ТЖК J, ТМК T, ТНН N, ТХКн E, ТПП R, ТПП S, ТПР B).
- Карточка: бейдж ТС/ТП (зелёный/янтарный), название, R₀·α или электроды, «НСХ: −50…200 °C», стрелка ›; hover/active, роль button + aria-label.
- CSS `.ts-*` (сетка auto-fill 240px / мобайл 150px, светлая тема через переменные и overrides).
- Карточки рендерит `renderTempSensorCards()` (идемпотентно) по каталогу `getTempSensorCatalog()` — 16 позиций в порядке бывших списков.
- Саблейблы меню КИП и А и SUBSECTIONS: «Термометры сопротивления и термопары».

### 2. Страница датчика (`#page-temp-sensor-view`, новая)
- conv-3col: (1) «Тип датчика» — чип с бейджем/названием/метой + диапазон измерения + шаг таблицы + «Рассчитать»; (2) заглушка + `#tempSensorResults`; (3) справка `#tempSensorInfo`.
- `openTempSensor(key)`: состояние `tempSensorKey`, заголовок «50М (Cu50) — термометр сопротивления» (мобайл) / крошки с именем датчика (десктоп, `updateDesktopBreadcrumb(null, name)` через navigateTo-хук), чип, дефолты 0/100/10, сброс результатов, справка под тип, вибро, переход.
- «Рассчитать» (`calcTempSensor`): таблица значений R(t) Ом / E(t) мВ + под ней блок «Расчёт произвольных значений» (Task 371, живой двусторонний t ↔ R/E с бисекцией и тостами вне НСХ).
- Реестры: PAGE_PARENTS (`temp-sensor-view` → `temp-sensors`), PAGE_LABELS («Датчик температуры»), топ-бар calculators, KipAuth._CALC_PAGES.
- navigateTo-хуки: карточки рендерятся при открытии списка; `temp-sensor-view` без выбранного датчика (прямой hash) → редирект на список.

### 3. Справочная информация — по типу датчика (заявка)
- Термометры (ТС): принцип ТС, параметры датчика (R₀, формула НСХ, диапазон), формулы ТС (медь/платина), температурные коэффициенты, ГОСТ 6651-2009 + IEC 60751. **Нет:** «Термопара», термо-ЭДС, ГОСТ Р 8.585-2001.
- Термопары (ТП): принцип ТП (эффект Зеебека), датчик (электроды, НСХ, E(0°C)=0 мВ), НСХ ГОСТ Р 8.585-2001 + полиномы НИСТ, распространённые типы. **Нет:** «Термопреобразователь», ГОСТ 6651-2009, IEC 60751, R(t).

### 4. Рефакторинг JS
- Удалены: `updateTempSensorOptions()`, select-ы `temp_sensor_type` / `temp_rtd_type` / `temp_tc_type`, контейнеры `rtd_options` / `tc_options`.
- Новые: `getTcSensorMap()` (имена ТП), `getTempSensorCatalog()` (единый источник: карточки, диапазоны НСХ, справка), `tempSensorFindByKey()`, `renderTempSensorCards()`, `openTempSensor()`, `tempSensorInfoHtml()`.
- Переписаны на состояние: `calcTempSensor()`, `getTempSensorRange()` (читает каталог), `tempCalcForwardValue()`, `tempQueryFromValue()` (единица Ом/мВ).
- `getRtdSensorMap()` (Task 371) не тронута; `tempCustomCalcHtml` / `tempCalcInvertValue` / `tempQueryFromTemp` без изменений.
