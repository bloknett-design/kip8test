# DEPLOY — Task 323: Итоги учёта — БОКОВАЯ ШТОРКА СПРАВА (kip8test)

**Дата:** 2026-09-05 · **Репо:** kip8test (тест) · **Кэш SW:** kipia-test-v561 → **kipia-test-v562**

## Заявка пользователя

«Перенеси бар итоги учёта в правую часть экрана сбоку и текст названия в баре
расположи по вертикали, при открытии он должен выдвигаться справа налево на
половину рабочей области, а в низу шахматки графика при этом появляется ползунок
для перемещения шахматки по горизонтали. Для удобства контроля по шахматке
расчётов итога. С этим учётом, строки итогов будут располагаться ровно по
строкам работников в шахматке, и поэтому список работников в панели итога
учёта можно убрать.»

## Что изменилось (только клиент — сервер/Apps Script/листы НЕ трогались)

1. **Рабочая область** `#wsWsBody` (`.ws-body`): десктоп — flex-строка
   «шахматка слева + шторка итогов справа»; сетка `#wsGridWrap` остаётся
   ВИДИМОЙ рядом с итогами (прежде, в Task 322, панель заменяла сетку).
2. **Вертикальный бар-ручка** `#wsTotalsBar` (`.ws-totals-vbar`, 28px):
   у ПРАВОГО края рабочей области; текст «Итоги учёта» / «дни и часы» —
   ПО ВЕРТИКАЛИ (`writing-mode: vertical-rl`); шеврон ◂ (закрыто) / ▸
   (открыто); клик/Enter/Пробел; aria-expanded; обе темы.
3. **Шторка** `#wsTotalsDrawer` (бар + панель): ширина 50% рабочей области,
   свёрнута — `margin-right: calc(-50% + 28px)` (торчит только бар),
   раскрытие — класс `ws-tt-open` на странице → анимация `margin-right`
   0.28s (выдвигается справа налево); панель `#wsTotalsPanel` со строкой
   вкладок Месяц/Год + скролл-контейнером `#wsTtBody`.
4. **Широкий режим сетки** (класс `ws-tt-gridwide`, только ≥1024px):
   таблица `width: max-content` + `table-layout: auto` (дни не сжимаются),
   контейнер `overflow-x: auto` с **ВИДИМЫМ ПОЛЗУНКОМ** внизу шахматки
   (12px, webkit + Firefox `scrollbar-width: thin`), колонка ФИО — sticky
   к левому краю (видна при любой прокрутке дней), шапка растёт до высоты
   заголовочной зоны панели (CSS-переменная `--ws-tt-head-h`, ставит
   `_applyTtHeadVar`). При сворачивании шторки режим держится 320 мс
   (анимация возврата без «сплющивания» колонок), затем `_ttCloseCleanup`.
5. **Строки итогов — ровно по строкам сотрудников** (`_syncTotalsRows`):
   каждой строке таблицы итогов задаётся измеренная высота строки сетки
   (целые пиксели `_fitGrid` / природные), вертикальный скролл синхронен
   сетка ⇄ панель (`_attachTotalsSync`, эхо-глушение `_ttEchoG/_ttEchoP`,
   панель не уезжает дальше сетки); бюджет `_fitGrid` в широком режиме —
   минус итоговая строка панели и минус ползунок (avail по clientHeight).
   Поэтому **колонка «Сотрудник» на десктопе в месяце СКРЫТА** (CSS
   `.ws-tt-table:not(.ws-tt-year)`); вкладка «Год» и мобайл — со списком
   (строки там не обязаны совпадать со строками сетки; год: активные в
   порядке сетки сверху, архивный персонал ниже).
6. **Таблица итогов**: итоговая строка — `tfoot`, прилипшая к низу панели
   (sticky, непрозрачная); обёртка `.ws-tt-scroll` удалена (скролл — сам
   `#wsTtBody`, полосы скрыты); инфо-строка однострочная (полная — в
   `title`); зебра и слова в шапке (Task 322) сохранены.
7. **Мобильная шторка** (<1024): fixed-оверлей справа ~86vw (74vh),
   transform-анимация (торчит бар 44px — тап-зона), список сотрудников
   виден, свой скролл.
