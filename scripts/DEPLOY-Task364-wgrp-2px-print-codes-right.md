## Что изменилось (только клиент, index.html)

1. **Рамка-группа выходных на экранной сетке — тоньше и бледнее (Task 363 → 364).**
   Толщина 3px → **2px**, цвет #e53935 → **#e57373** (спокойный красный) — те же шесть линий:
   верх (внутренняя тень на th шапки, border-top шапки по-прежнему 0 — Task 355), бока
   (border-left/right первого/последнего столбца группы на th и td), низ (border-bottom
   последней строки). Внутренняя грань Сб|Вс — тонкая 1px, фон обычных выходных = пустым
   ячейкам, праздники — розовые с заливкой даты (всё Task 363 — без изменений).
   **Кнопка увольнения `.ws-dismiss-submit` (#e53935) НЕ тронута** — это отдельный элемент.
2. **Печать: мероприятия и коды — ДВЕ КОЛОНКИ одного ряда.** Под таблицей вместо двух
   секций друг под другом — обёртка **`.wsp-bottom`** (flex-ряд): СЛЕВА столбик
   «Мероприятия · месяц · N» (`flex: 1 1 auto` — занимает остаток ширины листа),
   СПРАВА столбик «Коды:» (`flex: 0 0 auto`, `max-width: 44%` — в столбик, без
   растяжения). Зазор между столбиками 5mm, отступ от таблицы 2.5mm перенесён с секций
   на обёртку. Каждая запись мероприятия / каждый код — по-прежнему ОТДЕЛЬНОЙ строкой
   своего столбика (Task 360). Сноска `wsp-foot` («\* — сокращённый…») — ПОД обёрткой
   на всю ширину листа. Наполнение не менялось: фильтрация по виду и коды мероприятий
   в перечне (Task 362), ширина «Сотрудник»/шрифты/бейджи (Task 361).
3. **НЕ тронуты:** сама логика выбора мероприятий/кодов, справочник и порядок кодов,
   легаси-коды в конце, заглушка пустого месяца, итоговая строка отсутствует (Task 343).
