# Task 328 — Кнопка-иконка перекрёстной подсветки + кнопки меньше + тултипы по заявке (kip8test)

## Заявка пользователя

«Добавь кнопку в виде значка включения и отключения функции перекрёстной
подсветки строк и столбцов в шахматке графика. Расположи её слева от
кнопки "Сформировать". Сделай размер всех кнопок в баре над шахматкой
немного меньше. Всплывающие окна с подсказками при наведении указателя
мыши на два окна и кнопки "Итоги учёта", "Месяц", "Год", "Отменить"
убери, а на кнопке "Сформировать" сделай такого же формата как у
кнопки "Обновить".»

## Что сделано (только фронтенд, сервер/листы/Apps Script НЕ тронуты)

1. **Кнопка-ЗНАЧОК перекрёстной подсветки** — #wsCrossBtn (иконка svg:
   сетка 3×3 с ЗАЛИВАННЫМ перекрестьем строка+столбец) в ряду 3
   тулбара СЛЕВА от «Сформировать». Переключает Task 319 (наведение
   на ячейку выделяет строку И столбец): состояние `_crossOn`
   (true по умолчанию), метод `toggleCross` — сохранение выбора в
   localStorage (`kip8_ws_cross_v1`), синхронизация `aria-pressed`
   кнопки, выключение СРАЗУ гасит подсветку (`_cellHover(null)`),
   тост «Подсветка строк и столбцов включена/выключена». Гейт —
   в mouseover-делегировании (`if (self._crossOn === false) return;`),
   mouseout НЕ гейтится (гасит остаток). Восстановление из
   localStorage — в init. Видна всем ролям (фича просмотра);
   подпись для скринридеров — aria-label (видимой подсказки нет).
   Состояния: ВКЛ — синий тинт (как нажатый «Итоги учёта»), ВЫКЛ —
   нейтральная, иконка приглушена (0.55).
2. **Кнопки бара немного МЕНЬШЕ**: шрифт 14px → 13px
   («Сформировать»/«Сохранить»/«Отменить»/«Обновить»/«Итоги учёта»
   и селекты месяца/года), вкладки «Месяц»/«Год» 13px → 12px;
   паддинги 6px 14px → 5px 11px (кнопки), 6px 12px → 5px 10px
   («Обновить»/вкладки), 6px 10px → 5px 8px (селекты); единая
   высота 34px → 32px (и .ws-cancel-btn); иконка «Обновить»
   14px → 13px; ДЕСКТОП (≥1024px): padding 4px 12px → 4px 9px —
   ряды по-прежнему РОВНО 95px (Task 317), .ws-cross-btn —
   height 100% / width 34px.
3. **Всплывающие подсказки УБРАНЫ (заявка)**:
   - кнопки «Итоги учёта», «Месяц», «Год», «Отменить» — нативные
     title удалены из HTML;
   - окно мероприятий месяца (#wsEventsPanel): строки .ws-ep-item
     рендерятся БЕЗ title (переменная tip удалена из
     _renderMonthEventsPanel);
   - окно времени и праздников (#wsCalPanel): renderPanel без
     title — группа норм, бейдж «предварительно» (.ws-cal-prelim)
     и чипы праздников (.ws-cp-day) без всплывающих подсказок
     (monthsGen удалён — использовался только в тултипах).
4. **«Сформировать» — подсказка ФОРМАТА «Обновить»**: нативный
   title кнопки заменён ИНФОРМАЦИОННЫМ ОКНОМ #wsGenerateTip (класс
   .ws-refresh-tip + .ws-rt-date/.ws-rt-desc — тот же формат, что
   #wsRefreshTip, Task 317): заголовок «Сформировать шахматка» +
   описание (бывший title: месяц/год, обновление производственного
   календаря, диалог подтверждения). Показ при НАВЕДЕНИИ/фокусе,
   скрытие — уходом/blur/прокруткой (scroll-сброс скрывает ОБА
   окна); окно переносится в `<body>` (приём Task 319 — из-под
   stacking-контекста); позиция — НАД кнопкой, при нехватке места
   (с учётом верхнего бара) — ПОД ней (_showGenerateTip/
   _hideGenerateTip, зеркально Task 317/319).
