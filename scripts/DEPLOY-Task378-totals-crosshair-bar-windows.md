## Что сделано (только клиентский код — index.html, серверных шагов НЕТ)

### 1. Итоги учёта — «как в основной шахматке»
- **Фон ячеек значений** (месяц/год/архив, шторка + мобильная страница):
  светлая тема — **#FFFFFF**; тёмная — светлые цвета шахматки дней (Task 319):
  `#eef0f2` + `filter: brightness(0.88)` + тёмный текст `#141413`.
- **Зебра строк итогов (Task 322) УДАЛЕНА** — непрозрачные ячейки её не
  просвечивают; поле итогов — чистое белое с линиями шахматки.
- **Нули → пустые ячейки** в месячной таблице (`_renderTotalsMonth`):
  0 и «0» (часы) → пусто; ненулевые — как прежде.
- **Линии как в шахматке** (Task 355/377): значения —
  `rgba(0,0,0,0.30)` / `rgb(10,15,23)`; шапка — сталь
  `rgba(140,158,188,0.55)` / `rgb(83,96,117)`; колонка «Сотрудник» —
  `rgba(105,130,160,0.55)` / `rgb(64,80,102)`.
- Цветные колонки «Часы»/«Переработка» в тёмной теме — палитра светлой
  (`#1d7a37`/`#a06a13`): ячейки-то светлые.

### 2. Перекрестье — ФИО, итоги и яркость «сегодня»
- **Hover по ячейке ФИО** подсвечивает СТРОКУ (без столбца):
  делегирование ловит `td.ws-cell, td.ws-emp-col`.
- **Hover по ячейкам итогов** (шторка `#wsTtBody` + мобильная страница
  `#wsTtPageBody`) подсвечивает строку сетки И строку итогов
  (`_rowHover`); архивная таблица года `.ws-tt-arch` пропускается.
- **Яркость перекрестья = «сегодня»**: строка/столбец 0.30/0.22
  (= «сегодня»), пересечение 0.34/0.26, тройные 0.36/0.28; шапка
  hover-col 0.40/0.26 (= today-col), sel-col 0.44/0.30 (выбранный
  насыщеннее); строка шторки итогов 0.30/0.22. Гейт кнопки
  перекрестья действует на всё.

### 3. Окна «Мероприятия»/«Нормы» бара
- **Полоса прокрутки УБРАНА** (scrollbar-width:none +
  ::-webkit-scrollbar display:none — как Task 331); скролл остался
  колесом/свайпом/**клавишами ↑↓** (окна фокусируемы — tabindex="0").
- **Значок полного раскрытия** `.ws-bar-exp` в правом нижнем углу:
  шеврон; клик — окно раскрывается на ВЕСЬ текст (низ смещается вниз
  по количеству текста, высота = scrollHeight, плавный transition),
  повторный клик — обратно 95px; шеврон поворачивается на 180°.
- **Контраст по активности**: НЕ активен (свёрнуто) — приглушён
  (opacity 0.45); наведение/фокус/раскрытие — полная контрастность.
- Значок виден только когда текст НЕ влезает (или окно раскрыто);
  JS `_barExpSync/_barExpToggle/_barExpSyncAll` — пересчёт после
  каждого рендера окон, при ресайзе, загрузке шрифта, показе чипом.
