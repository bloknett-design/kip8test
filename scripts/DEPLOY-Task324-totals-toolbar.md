## Что изменилось (только клиент — сервер/Apps Script/листы НЕ трогались)

1. **Нижний ряд кнопок тулбара** `#wsBottomRow` (`.ws-toolbar-row
   .ws-bottom-row`): «Сформировать» + «Сохранить (N)» + «Отменить» —
   **В ОДНУ СТРОКУ** (заявка; прежде — ряд 2 «Сохранить/Отменить» и
   ряд 3 «Сформировали» отдельными строками, Task 315/317). Отдельные
   ряды `.ws-actions-row`/`.ws-generate-row` удалены; кнопки скрываются
   по состоянию (право записи / наличие правок), ряд всегда на виду —
   в нём всегда есть кнопки «Итоги учёта»/«Месяц»/«Год» (видны всем
   ролям), сетка под баром не прыгает. Разделитель `.ws-tb-sep` (1px,
   во всю высоту ряда) между действиями шахматки и блоком итогов.
   Десктоп: колонка кнопок = ДВА ряда × `calc((95px − 3px)/2)` = 46px
   (было три ряда × ~29,7px) — по-прежнему ровно высота окон (95px).
2. **Вертикальный бар-ручка УДАЛЁН** (`#wsTotalsBar`/`#wsTotalsChev`,
   Task 323): открытие/закрытие шторки — **кнопка-переключатель
   «Итоги учёта»** `#wsTotalsBtn` (`.ws-totals-btn`, `aria-pressed`,
   «нажатая» — синяя заливка) в нижнем ряду тулбара и **✕ в шапке
   шторки** (`#wsTtClose`, `.ws-tt-close`; мобайл — тап-зона 44px).
   Свёрнутая шторка теперь ПОЛНОСТЬЮ за правым краем: десктоп
   `margin-right: -50%` (было `calc(-50% + 28px)` — выступ под ручку),
   мобайл `transform: translateX(100%)` (было `calc(100% − 44px)`).
3. **Вкладки «Месяц»/«Год»** `#wsTtTabMonth`/`#wsTtTabYear`
   (`.ws-tt-tab`, активная — зелёная) — **ПЕРЕЕХАЛИ из шапки шторки
   в тулбар, СПРАВА от кнопки «Итоги учёта»**; клик по вкладке при
   закрытой шторке — открывает её сразу с нужной вкладкой
   (`setTotalsTab` → `toggleTotals`, если закрыта).
4. **Шапка шторки** `.ws-tt-head` (бывшая строка вкладок `.ws-tt-tabs`):
   только ✕, аварийная строка ⚠ `#wsTtWarn` (сбои загрузки месяцев
   года/отсутствие справочника — ставит `_setTtWarn`, янтарная,
   пустая скрыта) и «Обновить» (год, справа). **Пояснительная
   инфо-строка `#wsTtInfo` УДАЛЕНА** (месяц/норма — в окне календаря
   тулбара, счётчик правок — на кнопке «Сохранить (N)»).
5. **Оглавления — ОДНИМИ СТРОКАМИ** (заявка): `.ws-tt-table th` —
   `white-space: nowrap` (было `normal` + перенос, Task 322); таблица
   шире панели прокручивается новым ползунком (п.6). Высота th ≈ 22,5px
   (одна строка) — шапка сетки (--ws-tt-head-h = шапка шторки + шапка
   таблицы) остаётся ниже, строки итогов — по-прежнему ровно по строкам
   сотрудников (`_syncTotalsRows`/`_applyTtHeadVar` не изменились).
6. **Нижняя горизонтальная полоса прокрутки В ШТОРКЕ** (заявка):
   `#wsTtBody` — webkit: горизонтальная полоса ВИДИМАЯ (12px, бегунок

   скролл Y синхронен с сеткой); Firefox — тонкие полосы
