# Task 356 — Шахматка табеля: точки «·» убраны и из пустых ячеек (рабочие дни)

**Заявка пользователя:**
> «пустые ячейки без кодов событий тоже должны быть без точек»

Развитие Task 355 (там точка «·» была убрана только в нерабочих
выходных/праздничных ячейках). Теперь центр ячейки ПУСТ у ВСЕХ ячеек
без кодов — на любых днях.

## Что изменилось

`_renderCell` (контент ячейки):
- было: `(showMainCode ? status : (vacPlan ? 'ОТ' : (dayOff ? '' : '·')))`
- стало: `(showMainCode ? status : (vacPlan ? 'ОТ' : ''))`

Коснулось (визуально — чистый центр):
- пустая ячейка рабочего дня без записи;
- «.» (плановый выходной) — маркер-класс `ws-dot-code` и фон как у
  пустой остаются, код «.» по-прежнему виден в попапе клика;
- статус-мероприятие (И/ОБ/ПЗ/ПР/*) — центр пуст, мероприятие видно
  сплошным бейджем в правом нижнем углу (как на выходных после 355).

НЕ тронуто:
- коды смен/неявок (Д/Н/Д8/д/ОТ/Б…) — большой код + inline-фон;
- планы отпусков «ОТ» + пунктирная рамка ws-vac-plan;
- бейджи мероприятий (сплошные/пунктирные) и плановых смен;
- метка «·» в попапе выбора статуса и select «Дополнительно…»;
- розовый выходных #f8e2e9, линии 1px (30% чёрного / стале-голубые),
  красные стыки Task 255 — всё из Task 355 живо.
