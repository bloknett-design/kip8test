## Что изменилось (заявка пользователя)

> «В карточке сотрудника убери строки "Шаблон ротации", "Сотрудник",
> "Итого в году". Убери пояснительные окна при наведении на ячейки
> сотрудников и шахматки. Кнопку "+ Сотрудник" убери, а её функцию
> должно выполнять заглавие ячеек сотрудников "Сотрудник",
> расположенное в шапке над ними.»

1. **Карточка сотрудника** (`_renderEmpPopup`):
   - строка «Шаблон ротации» убрана (данные живы в шторке «+ Сотрудник»
     и на сервере);
   - строка-заголовок «Сотрудник» (секция профиля) убрана — поля идут
     сразу после шапки ФИО;
   - итог-строка года отпусков («Итого в году: N … лимит 42») убрана
     вместе с красным «ПРЕВЫШЕН» и CSS `ws-emp-total`/`ws-emp-overlimit`;
     контроль лимита 42 дн. (Task 310) полностью остался в шторке
     «+ Отпуск» (строка годового лимита + жёсткая блокировка отправки);
   - дни периодов — по-прежнему «чистые» за вычетом праздников ст. 112
     (Task 310), с пометкой «(−N праздн.)».

2. **Пояснительные окна при наведении убраны**:
   - карточка сотрудника теперь открывается **только кликом** (в т.ч. на
     таче): удалён `_attachEmpPopupHover` (делегированные mouseover/mouseout,
     таймеры 350/400 мс, mouseenter/mouseleave попапа, медиа-запрос
     `(hover: hover)`, `_empHoverAttached`/`_empOpenTimer`/`_empCloseTimer`/
     `_scheduleEmpPopupClose`);
   - `_openEmpPopup(td, tabNo)` — без параметра `pinned` (режим всегда
     прикреплённый: кловер active, закрытие — фон/Esc);
   - с **ячеек шахматки** и **шапки сетки** убраны все `title`-тултипы:
     статус/название, праздник (ст. 260), сокращённый день, мероприя-
     тия (ст. 303), план отпуска «заполнится кодом…» (ст. 274/298),
     плановая смена «по циклу» (ст. 305), «не сохранено» (ст. 251) —
     информация осталась в попапе клика, карточке сотрудника и окошке
     производственного календаря в тулбаре; бейджи/маркеры в ячейках живы.

3. **Кнопка «+ Сотрудник» → заголовок «Сотрудник»**:
   - кнопка `#wsEmpBtn` и класс `.ws-addemp-btn` удалены из HTML и CSS
     (правила высоты 34px и нейтрального стиля — теперь только для
     «+ Отпуск»);
   - `init()` больше не управляет её видимостью;
   - заголовок `thead th.ws-emp-col` в `_renderGrid` становится кнопкой
     **только ролям с правом правки**: класс `ws-emp-head-add`,
     `onclick="WorkSchedule.openEmployeeForm()"`, плюсик-индикатор
     «+» акцентом, курсор-палец, подсветка при наведении (тёмная +
     светлая темы); зрителям — обычный заголовок без клика;
   - двойная защита: `openEmployeeForm` сам проверяет `_canEdit`.
