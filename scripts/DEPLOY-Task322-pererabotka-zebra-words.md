# Task 322 — Деплой: переработка д/н в итогах, слова в шапке, зебра, панель на всю высоту

**Что сделано (kip8test, клиент + сервер WorkSchedule.gs):**

1. **Коды «д»/«н» — ДНИ ПЕРЕРАБОТКИ в «Итогах учёта»** (заявка):
   - сменному персоналу — по **12 часов** каждая д/н;
   - дневному — по **часам, указанным при добавлении кода в ячейку шахматки**:
     выбор «д»/«н» у дневного в попапе ячейки открывает **малую форму часов**
     (префилл 8, ввод 0,5–24, Enter/«Готово», «Назад к кодам»); те же часы —
     полем **«Часы (для кодов д/н — переработка)»** в шите «Дополнительно…»;
     часы записи показываются в списке кодов попапа («· 7,2 ч»);
   - д/н больше НЕ считаются явками/часами/Д/Н — только «Переработка»
     (дни — в тултипе ячейки колонки) + «Всего»;
   - старые записи д/н без часов (до Task 322) — фолбэк **8 ч**;
   - годовая вкладка — колонка **«Перераб.»** (часы д/н за год).

2. **Шапка итогов — слова вместо кодов**: День (Д), Ночь (Н), Отпуск (ОТ),
   Уч. отпуск (У), Отгул (ОВ), Больничный (Б), Прогул (ПР), Переработка,
   Прочие, Всего, Явки, Часы.

3. **Оформление**: строки таблицы — **зебра** (тёмная rgba(255,255,255,0.09),
   светлая rgba(0,0,0,0.07)); раскрытая панель — **на всю высоту шахматки,
   до бара с кнопками** (вид переключается: сетка скрывается классом
   `ws-tt-open`, панель `flex: 1` до низа окна; сворачивание возвращает
   шахматку; мобильный — панель ≤70vh, страница скроллится).

4. **Сервер (WorkSchedule.gs)**: `listEntries` читает 11 колонок — новое поле
   `часы` (число/null, строки «7,2» нормализуются); `setManualEntry`
   принимает `часы` (валидация 0,5–24) и пишет **колонку K** листа
   «Записи_графика». Старый клиент поле не шлёт → K не трогается
   (обратная совместимость); `null` → часы чистятся (смена статуса).
