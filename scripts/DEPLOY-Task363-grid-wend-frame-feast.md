# DEPLOY Task 363 — шахматка: фон выходных как пустые, красная рамка-группа вокруг столбцов выходных, розовые праздники + их даты

**Дата:** 2026-09-10
**Заявка пользователя:** «В шахматке табеля фон выходных дней сделай таким же как в пустых ячейках. А на
ячейках выходных дней сделай толстые красные разделительные линии вокруг по краям группы этих ячеек
(не каждую ячейку), включая ячейки с датами. А нерабочие праздничные дни оставь светлым розовым
фоном, только добавь такой же фон и на их ячейки с датами.»

## Что изменилось (только клиент, index.html)

1. **Фон обычных выходных = фон пустых ячеек** (заявка 1): прежние розовые правила
   `.ws-weekend.ws-status-empty` (тёмная #6e4250/#f8e2e9, светлая #f8e2e9) удалены —
   пустые ячейки Сб/Вс и перенесённых выходных берут базовый фон `.ws-cell`
   (#eef0f2, обе темы несут светлые цвета с Task 319). Класс-маркер `ws-weekend`
   остаётся (семантика/тесты). Статусные ячейки (Д/Н/Б/д/н…) на выходных, как и
   прежде, несут inline-цвет справочника.
2. **Толстая красная рамка вокруг ГРУППЫ столбцов выходных** (заявка 2): 3px #e53935
   по краям группы (не каждую ячейку), включая шапку с датами: верх — внутренняя
   тень `inset 0 3px 0 0` на th шапки (border-top шапке запрещён Task 355 — высота
   37px и совпадение со шторкой итогов Task 331 не тронуты); бока — border-left/right
   на th и td первого/последнего столбца группы (в `border-collapse` широкая граница
   всегда перекрывает 1px соседа — красить рабочий день по другую сторону стыка не
   нужно); низ — border-bottom на последней строке (`tr:last-child`). Внутренняя
   грань Сб|Вс остаётся тонкой. Заменила тонкие 1px-линии стыков Task 255
   (классы/правила `ws-boundary-*`, #cc6e73 — удалены полностью). Группа = подряд
   идущие обычные выходные; край таблицы = край группы (нерабочий 1-го числа получает
   левую границу, последнего дня — правую).
3. **Праздники — розовый фон + заливка их ячеек дат** (заявка 3): нерабочие
   праздничные дни (ст. 112, `dInfo.holiday`) — прежний пастельный #f8e2e9
   (Tasks 254/355) у ПУСТЫХ ячеек тела (селектор `.ws-feast.ws-status-empty`, база
   + светлая тема) и ТА ЖЕ заливка на ячейке даты в шапке (`th.ws-feast
   background`); ярко-красный жирный текст даты праздника (Task 260) сохранён.
   Праздники в красную рамку-группу НЕ входят.
4. **Новые хелперы:** `_calDayFeast(day)` — праздник ст. 112 по производственному
   календарю (без календаря — false); `_calWend(day)` — обычный выходной
   (нерабочий, НЕ праздник). `_renderGrid` ставит `ws-wgrp`/`ws-wgrp-first`/
   `ws-wgrp-last` на th, `_renderCell` — на td (гварды typeof для старых
   VM-хостов).
5. **НЕ тронуты:** печатная форма графика (wsp-*, Tasks 341–362 — своя вёрстка),
   подсветки «сегодня»/наведённой/выбранной даты (Tasks 313/316), бейджи
   мероприятий (Tasks 303/314), план отпуска, зебра ФИО, попапы.

## Проверка за 5 минут

1. Открыть «Табель учёта рабочего времени»: пустые ячейки Сб/Вс — такие же
   серо-голубые, как у рабочих дней (розовых выходных больше нет).
2. Каждая группа выходных (Сб+Вс, включая перенесённые одиночные дни) обведена
   толстой красной рамкой сверху донизу: верх проходит по шапке с датами, низ —
   под последним сотрудником; между Сб и Вс линии нет (только по краям группы).
3. Нерабочий праздничный день — розовые пустые ячейки + розовая ячейка даты в
   шапке (например, 4 ноября); красной рамки вокруг него нет.
4. Нерабочие с кодами (д/н/ОТ…) сохраняют свои цвета и внутри рамки.
