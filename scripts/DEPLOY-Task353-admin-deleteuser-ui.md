## Что видит администратор

| Где | Что |
|---|---|
| Админ-панель → «Пользователи» | в каждой карточке появилась красная кнопка **«Удалить»** (правее «Сбросить вход») |
| своя строка | кнопка серая (неактивна), при наведении — «Нельзя удалить собственный аккаунт» |
| клик «Удалить» (чужая строка) | модалка **«Удалить пользователя?»** с email, предупреждением о безвозвратности (строка users + все сессии + активные OTP) и кнопками «Отмена» / «Удалить» |
| «Удалить» в модалке | запрос к серверу → тост «Пользователь удалён: … (сессий закрыто: N)» → списки «Пользователи» и «Сессии» перезагружаются — юзер исчезает |
| отказ сервера (гарды Task 351: «последний админ», «User not found», сеть) | текст ошибки — **внутри модалки** (красным, под кнопками), модалка остаётся открытой, кнопка снова активна — можно повторить или отменить |
| Журнал событий | в фильтр добавлена опция «Удаление пользователя» (`ADMIN_DELETE_USER`) |

Защита от случайного клика — двойная: подтверждение в модалке +
тост нельзя пропустить. Отмена — кнопкой «Отмена», крестиком или
кликом по фону.

## Технические детали

- Вызов: `KipAdmin._api('adminDeleteUser', { userId })` — тот же
  конвейер (token + гейт admin.panel на сервере), что у смены роли.
- Email цели в модалке вставляется через `textContent` —
  XSS-безопасно без экранирования.
- Кнопка «Удалить» блокируется на время запроса («Удаление…») —
  двойной клик не отправит два запроса.
- Устаревший список (юзер уже удалён с другого устройства): клик
  молча игнорируется — после перезагрузки списка строки нет.
- Ответ старого сервера без `sessionsRemoved` — тост без деталей
  (обратная совместимость).

## Проверка после деплоя (5 минут)

1. Обновить приложение (Ctrl+Shift+R). Войти как Админ →
   Админ-панель → «Пользователи»: у каждой строки есть «Удалить»,
   своя строка — серая кнопка.
2. Создать тестового юзера «+ Добавить» → «Удалить» → модалка с
   его email → «Удалить» → тост, юзер исчез из списка, из «Сессий»
   его строки тоже пропали.
3. Журнал событий: фильтр «Удаление пользователя» → строка
   `ADMIN_DELETE_USER` с деталями.
4. Попробовать удалить единственного другого админа (если он
   последний): ошибка «Нельзя удалить последнего админа» — в
   модалке, не тостом.
5. «Отмена»/крестик/клик по фону — модалка закрывается, запроса
   нет (журнал не пополняется).
