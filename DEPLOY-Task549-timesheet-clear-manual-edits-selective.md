## Что изменилось

Диалог подтверждения кнопки **«Очистить правки»** (Task 548) стал **списком
чекбоксов** — удаление **каждой правки по отдельности** (заявка: «в диалоговом
окне подтверждения удаления ручных правок сделай возможность удаления каждой
правки по отдельности с кратким наименованием правок (пример краткого
содержания — работник/дата правки/наименование правки)»).

- **новый диалог `kipConfirmList`** (общий оверлей/анимация `kipConfirm`):
  строки-чекбоксы, «Выбрать все / Снять все», счётчик «Выбрано: N из M»,
  блок OK при пустой выборке, Escape — отмена;
- **строка правки**: «РАБОТНИК · ДАТА · НАИМЕНОВАНИЕ ПРАВКИ» — ФИО из
  справочника (нет — «таб. № X»), дата ячейки `dd.mm.гггг`, краткое
  обозначение кода из «Коды_статусов» (неизвестный код → «код «X»»,
  пустой/«.» → «Выходной»); серым мелким — тип правки («ручная запись на
  сервере» / «несохранённая правка» / «авто-подмена, материализована») и
  комментарий записи (≤40 симв.); порядок строк — по дате, затем таб-номеру;
- **OK применяется только к отмеченным** (по умолчанию отмечены все — прежнее
  поведение «очистить всё»): `__delete`/снятие правок, снятие меток реестра
  `ws_auto_dn_keys` и тост «Очищено правок: N» — **по выборке**; отмена —
  ничего не меняется; записи «авто» и архивные табы не затрагиваются;
- фолбэк-среды без `kipConfirmList` — прежний `kipConfirm` danger со
  счётчиком (очистка всего).
