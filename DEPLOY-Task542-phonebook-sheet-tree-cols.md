# DEPLOY Task 542 — Телефонный справочник: свёрнутое дерево при входе, «Избранное» в 3 столбца, обновление из Google Sheets

> Дата: 2026-10-21 · Заявка: «При входе в раздел дерево должно быть
> свёрнуто, кроме группы ООО ПО "ТОКЕМ", и в десктопе отображение
> контактов в избранном раздели на три столбика. Теперь необходимо
> сделать телефонный справочник обновляемым, вот ссылка на файл с
> данными https://docs.google.com/spreadsheets/d/1phGnzRS…/edit»

## Что сделано (КЛИЕНТ — сервер Apps Script не менялся)

- **Дерево при входе свёрнуто, кроме ООО ПО «ТОКЕМ»** (десктоп,
  вкладка «Все»): при каждом входе в раздел (pbInit после загрузки
  данных) все организации свёрнуты, ООО ПО «ТОКЕМ» — раскрыта
  (`PB_DEFAULT_OPEN_ORG` + `pbMasterApplyDefaultCollapsed`). Ручные
  развороты живут внутри раздела (Task 541: переживают смену таба и
  сброс выбора), при повторном входе — сброс к умолчанию. Новые
  организации в таблице автоматически попадают в «свёрнутые».
- **«Избранное» на десктопе — ТРИ столбца**: вкладка «Избранное» без
  поискового запроса (класс `pb-fav-cols`) — карточки-плитки в сетке
  `repeat(3, 1fr)` (заголовки групп на всю ширину, рамки/скругления,
  обе темы). Поиск, вкладка «Все» и мобильная версия — прежний
  одноколоночный список.
- **Обновляемые данные из Google Sheets**: `scripts/sync-phonebook.py`
  скачивает XLSX-экспорт таблицы пользователя (доступ «у кого есть
  ссылка», без секретов) и пересобирает `data/phonebook.json`.
  Workflow `sync-phonebook.yml` — ежедневно 03:50 UTC (10:50 Нск) +
  ручной запуск (`workflow_dispatch`); при изменениях — авто-коммит
  «auto: update phonebook data from Google Sheets». Первый синк уже
  выполнен: 5 организаций, 220 записей (вместо 236 из XLS от
  01.06.2026 — таблица теперь источник истины).
- **Правила разбора плоской таблицы** (форматирование исходного XLS
  при импорте в Google Sheets потеряно — структура только по
  наполнению строк): строка только с колонкой A — заголовок («ООО…» →
  организация, иначе — подразделение); строка с Ф.И.О. и/или
  телефоном — контакт; строки до первого заголовка «ООО…» —
  организация `ООО ПО «ТОКЕМ»` (стабильный ключ = стабильные ID
  избранного). Подгруппы третьего уровня плоской таблицей не
  выражаются (subgroup = null, схема сохранена).
- **Упрочнение синка** (гонка, пойманная браузерной верификацией):
  merge при ещё не загруженных данных (`pbFlat` пуст — повторный вход
  перезагружает данные, синк опережает загрузку) больше НЕ считает
  серверские id «не существуют в справочнике» (guard `haveData`) —
  раньше это мягко удаляло всё избранное каскадом и на сервере.
- SW: kip8test `kipia-test-v753 → v754` (216 файлов, гварды v755
  первыми) — kip8: `kipia-v550 → v551` (217 файлов, гварды v552).
- Тесты: НОВЫЙ `tests/test-task542.js` ×30 (SRC×20 + VM×10) +
  **раннер `tests/run-all.js` сам поднимает лимит кучи до 2560МБ**
  (re-exec с `--max-old-space-size`; суит вырос до ~2ГБ live-данных —
  на 4ГБ-машинах дефолт node ~2ГБ и прогон падал OOM уже на чистом
  дереве Task 541; CI не требует изменений) — 7214/0 → 7244/0
  (оба репо, ПАРИТЕТ).

## Как обновлять справочник

1. Править таблицу:
   https://docs.google.com/spreadsheets/d/1phGnzRS1UPtl6G6jcfnt34jlqlKYhGn_/edit
   (лист «Лист1», колонки: Должность | Ф.И.О. | № тел.).
2. Ждать cron (10:50 Нск) ИЛИ GitHub → Actions → «Update Phonebook
   (TEST)» → Run workflow.
3. Пользователю в приложении — Ctrl+Shift+R (данные подтягиваются
   при следующем входе в раздел: pbLoad — network-first с
   cache-busting; SW SWR + DATA-кэш уведомляет открытые вкладки).

## Деплой

1. **КЛИЕНТ (GitHub Pages)**: пушем (CI + Pages). Пользователю —
   **Ctrl+Shift+R** один раз (SW обновится сам, v754/v551).
2. **СЕРВЕР — НЕ ТРЕБУЕТСЯ**: Task 542 не менял серверную часть

3. **ИНФРА**: workflow `sync-phonebook.yml` создаётся пушем сам;

## Откат

- `git revert <commit>`; workflow можно удалить/отключить вручную.
  localStorage (избранное/примечания/очередь) не тронут; данные
  phonebook.json откатятся к XLS-версии (236 записей) вместе с
  revert'ом коммита.

## Проверка после обновления

- Десктоп, вкладка «Все»: дерево организаций свёрнуто, ООО ПО
  «ТОКЕМ» раскрыта (подразделения видны); шеврон разворачивает
  свёрнутую организацию; уход из раздела и возврат — снова свёрнуто,
  кроме ТОКЕМ.
- Десктоп, вкладка «Избранное» (при 3+ избранных): карточки в три
  столбца; поиск — одноколоночный; мобильная версия — одна колонка.
- Данные соответствуют таблице: например, счётчик «Все» = 220 (по
  состоянию таблицы на 21.10.2026).
- Тихая синхронизация (Task 540) работает как прежде; избранное
  переживает повторные входы в раздел (упрочнение merge).
