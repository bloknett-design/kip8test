# Task 414 — блок инструктажей в карточках работников: список только добавленных записей

**Заявка:** «В блоке Повторные инструктажи и периодическая проверка знаний
в картах работников должен быть список только добавленных записей, не нужно
показывать все 5 групп».

## Что изменилось

В карточке работника (страница «Работники») блок «Повторные инструктажи и
периодическая проверка знаний · год ‹›» теперь показывает **только
добавленные записи выбранного года** — плоский список строк:

```
[цвет] И  Повторный инструктаж по рабочим инструкциям ОТ · 15.01.2026  ✎ ✕
[цвет] ПЗ Периодическая проверка знаний на допуск… · 20.03.2026        ✎ ✕
```

Убрано (в карточке):

- заголовки-групп всех 5 пунктов «Список_И_и_ПЗ»;
- строки «— не проводился» / «— за N год не проводился»;
- строки «след. срок: … ✓» / «⚠ просрочено с …»;
- разделитель «вне списка:» — записи без соответствия шаблону показываются
  обычными строками вперемешку (они тоже добавленные).

Пустой год — «нет инструктажей и проверок знаний за год». Стрелки ‹год›
(архивы Task 408) работают как прежде: в каждом году — плоский список
записей того года.

**Попап ячейки шахматки** (клик по фамилии в сетке) — без изменений:
компактный групповой вид по шаблону (только непустые пункты, «след. срок»),
как в Task 407/408.

Форма «+ Инструктаж…» (Task 410–412) не менялась.

## Серверные шаги

**НЕТ** — менялся только index.html. Актуальные серверные шаги прежних задач
(если ещё не выполнены): обновить WorkSchedule.gs в Apps Script +
НОВАЯ ВЕРСИЯ развёртывания + разово instrListInit (Task 409/412/413).

## Что проверять

1. Открыть «Работники» → карточка работника с записями: в блоке только
   записи «тема · дата» (код И/ПЗ, ✎/✕ редактору), без заголовков групп;
2. Стрелка ‹ года — записи прошлого года, тоже плоским списком;
3. Попап ячейки сетки — прежний вид с группами;
4. «+ Инструктаж…» — форма с выбором пункта «Список_И_и_ПЗ» и одной датой.
