# Task 412 — форма «+ Инструктаж…»: список Список_И_и_ПЗ всегда (встроенный эталон при пустом сервере)

**Заявка:** «Нет выпадающего списка в форме выбора инструктажа и проверки знания,
просто пустое поле для ручного ввода, а должен быть список из таблицы
"Список_И_и_ПЗ"».

## Диагноз (почине­ние без изменения сервера)

Select пунктов строится из `_INSTR_LIST`, который приходит с сервера в ответе
`workSchedule.listTrainings.instrList` (лист «Список_И_и_ПЗ» таблицы
табель_КИП_ИОС). Клиентская логика (Task 407–411) корректна, но **боевой Apps
Script не отдал ни одного пункта** — Apps Script проекта не обновлён до версии
Task 407/409, либо лист «Список_И_и_ПЗ» не создан, либо после вставки кода не
создана новая версия развёртывания (деплой продолжает отдавать старый код).
Защитная деградация Task 407 («шаблона нет — свободный ввод») превратилась в
видимую проблему: форма показывала пустое текстовое поле.

## Что сделано (только клиент — index.html; сервер НЕ менялся)

### Встроенный эталон `_INSTR_CANON` (паттерн канона Task 387)

- в состояние WorkSchedule добавлен **`_INSTR_CANON` — ровно 5 пунктов заявки
  409, байт-в-байт как пишет `instrListInit`** (WorkSchedule.gs):
  1. Повторный инструктаж по рабочим инструкциям ОТ — инструктаж, 6 мес;
  2. Повторный инструктаж по инструкции № 9-ОГЭ — инструктаж, 3 мес;
  3. Периодическая проверка знаний на допуск к самостоятельной работе —
     проверка_знаний, 12 мес;
  4. Периодическая проверка знаний на допуск к проведению работ в
     электроустановках до 1000 В — проверка_знаний, 12 мес;
  5. Периодическая проверка знаний по охране труда при выполнении работ на
     высоте — проверка_знаний, 12 мес, основание «инструкция № 53-ОТ»;
- новый метод **`_normalizeInstrList(list)`**:
  - живой список (хотя бы один пункт с названием) — **источник правды**,
    возвращается как есть (строки без названия отфильтровываются);
  - пустой список (Apps Script старый / лист не создан / кэш прежней версии) —
    **замещается копией канона** + `console.warn('[Список_И_и_ПЗ] сервер не
    отдал ни одного пункта — работает встроенный эталон…')` (диагностика);
- применение в **обоих** местах наполнения:
  - `_loadTrainings`: `self._INSTR_LIST = self._normalizeInstrList(data.instrList)`;
  - `_restoreCachedView`: `this._INSTR_LIST = this._normalizeInstrList(
    Array.isArray(c.instrList) ? c.instrList : [])` (guard Task 407 сохранён).

### Что это даёт пользователю уже сейчас (без серверных шагов)

- форма «+ Инструктаж…» — **всегда строгий select** (не пустое поле ручного
  ввода): 5 пунктов, группы «Инструктажи» (2) / «Проверка знаний» (3), тип
  записи = «вид» пункта, подсказка «раз в год · Основание: инструкция
  № 53-ОТ», правка «вне списка» — отдельный пункт (Task 410 без изменений);
- карточка работника — **групповой вид** 5 групп с подписями «раз в 6 месяцев /
  3 месяца / год» (не плоский список), «вне списка:», «— не проводился»;
- кэш прежней версии и оффлайн — то же поведение (канон до первого
  «Обновить» с живым сервером).

### Границы

- живой лист всегда главнее: после обновления Apps Script + `instrListInit` +
  «Обновить» список придёт из таблицы (в т.ч. с правками пользователя);
- форма мероприятия («+ Мероприятие…», попап ячейки) — без изменений: типы
  обучение/прогул/примечание, тема свободная, период дат (Task 411);
- сервер WorkSchedule.gs в репо не менялся — серверные шаги Task 409 остаются
  актуальными, см. ниже.

## Серверные шаги (та же инструкция, что Task 409 — НЕ обязательны для
работы формы после Task 412, но нужны, чтобы список шёл ИЗ ТАБЛИЦЫ)

1. Открыть проект Apps Script таблицы «табель_КИП_ИОС» → заменить содержимое
   `WorkSchedule.gs` кодом из репо (scripts/WorkSchedule.gs);
2. **Создать новую версию развёртывания** (Deploy → Manage deployments → Edit →
   Version: New version → Deploy) — иначе /exec продолжает отдавать старый код;
3. разово запустить `instrListInit` (редактор → выбор функции → Run) — создаст /
   приведёт лист «Список_И_и_ПЗ» к 5 пунктам эталона; **после ручного заполнения
   листа функцию больше не запускать** (замещает строки);
4. в приложении нажать «Обновить» — список теперь приходит из таблицы.
