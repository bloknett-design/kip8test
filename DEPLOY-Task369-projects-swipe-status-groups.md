## Что изменилось (только клиент index.html + sw.js)

### 1. Кнопка «Проекты» — свайп-ячейка (как «Приборы»/«Клапана»)
- Кнопка обёрнута в свайп-ячейку `#projectSwipeCell`
  (`.dev-swipe-cell.project-swipe-cell`) с двумя подложками
  `.dev-swipe-bg` — «По статусу» слева и справа (янтарно-коричневый
  градиент в цвет кнопки `#b08048`, тёмная/светлая темы).
- Обработчики pointer-событий (порог направления 12px, доминирование
  горизонтали ×1.5, overshoot-резинка 0.3, вибрация 10/20 мс):
  - **тап** → «По отделениям» (`projects-prod`, как раньше);
  - **свайп в любую сторону** (порог перехода 30 % ширины) →
    «По статусу» (`projects-status`). Оба направления ведут на одну
    страницу — альтернативная группировка у проектов одна.
- Недоведённый свайп возвращает карточку на место; вертикальное
  движение — скролл (свайп отменяется); `projectSwipeMoved` гасит
  click после свайпа; `touch-action: pan-y`.
- Отступ ячейки выровнен со строками меню (зазор 6px между строками
  сохранён — `#page-kip-ios > .menu-btn-row .dev-swipe-cell
  { margin-bottom: 0 }`).

### 2. Страница «Проекты по статусу» (`#page-projects-status`)
- Заголовок с хлебными крошками «Главная / Документация / КИП ИОС /
  Проекты по статусу», поиск (тот же паттерн
  `projectsRenderSorted('status')`), инфо-бар.
- **Группы — по столбцу «Статус проекта»** листа «Проекты»:
  порядок фиксирован `PROJECT_STATUS_ORDER`:
  «Новый» → «Выполнен» → «Остановлен» → «Отменен»/«Отменён» →
  неизвестные статусы по алфавиту → «(без статуса)» в конце
  (`projectStatusGroupKey` / `projectStatusSortKey`).
- Внутри группы — по «Дате утв.» от старых к новым (как в
  «По отделениям»); тап по группе открывает `project-group`
  с подгруппами по годам (переиспользован существующий механизм,
  фильтр группы по `projectStatusGroupKey` в режиме `status`).
- `projectInitSorted('status')` при навигации; зарегистрирована во всех
  реестрах страниц: `PAGE_PARENTS` (родитель `kip-ios`), названия,
  хвосты истории/свайп-навигации, кэш страниц.
