деплой GitHub Pages автоматически) + СЕРВЕР Apps Script (по этой инструкции —

## Суть изменений

| Элемент | Было (Task 463) | Стало (Task 464) |
|---------|-----------------|------------------|
| Подсказка над таблицей | «Нажмите на ячейку месяца…» | **Удалена** (заявка) |
| Ширина колонки мероприятий | фикс. 300px, текст переносится | **по тексту** (без переносов, по самому длинному наименованию) |

### 2. Apps Script: маршрутизация Code.gs

`case 'planEvents.mark':` — эталон `scripts/Code.gs` уже содержит их:

## Проверка после деплоя

1. Открыть «Плановые мероприятия»: подсказки над таблицей больше нет; колонка
   мероприятий шириной по тексту.
2. Клик по пустой ячейке → диалог: [Отмена (слегка красная)] [Подтвердить] →
   зелёная галочка (как в Task 463).
3. Клик по ОТМЕЧЕННОЙ ячейке → диалог «Изменение отметки» с датой отметки →
   изменить дату → «Сохранить дату» → title ячейки и архив обновлены.
4. Снова клик по отмеченной → «Удалить отметку» → ячейка вернулась к крестику;
   строка исчезла из листа «Архив» файла Мероприятия_КИП_ИОС.
5. Мобильный (≤ 1023px): селектор «Месяц» над таблицей, видны только
   мероприятия и выбранный месяц (по умолчанию текущий); выбор другого месяца
   переключает столбец.
