## Что менялось (КЛИЕНТ + СЕРВЕР)

### 1. Анимация переворота клетки с бликом по глянцу + вибрация (`index.html`)

| Элемент | Реализация |
|---------|-----------|
| Переворот | `@keyframes msCellFlip` — клетка поворачивается `rotateY(90°→0°)` со сжатием `scale(0.72→1)` за 0.45 с (cubic-bezier); `perspective: 900px` на `.ms-board` — 3D-глубина; `fill: backwards` — до старта клетка «ребром» |
| Блик по глянцу | `::after` у `.ms-cell-flip` — диагональная (`105deg`) полоса белого градиента (пик `rgba(255,255,255,0.55)`, на светлой теме `0.85`) скользит поперёк грани за клеткой (`@keyframes msCellShine`, `translateX(320%)`); `animation-delay: inherit` — блик ждёт СВОЙ переворот; скос `skewX(-18deg)` — «глянцевый» след |
| Волна | ново-открытые клетки хода (клик + автораскрытие пустых + мины при взрыве) переворачиваются с задержкой `msFlipDelay = min(dist·35, 385)` мс от эпицентра (Chebyshev-расстояние) — каскад от места клика/взрыва |
| Вибрация | `msVibrate(12)` — отклик на открытие клетки; `[80,60,120]` — взрыв; `[40,40,40,40,100]` — победа; обёртка `msVibrate()` — iOS Safari (нет `navigator.vibrate`) не падает; флаг долгим нажатием — прежние 30 мс |
| Отложенный финал | `msDelayedOverlay(…)`: оверлей взрыва — через 750 мс (волна мин отыгрывает), победы — через 650 мс (флаги на мины и оверлей после волны последних клеток); гвард `msGameId` — «новая игра» в паузе отменяет отложенный оверлей |
| Доступность | `@media (prefers-reduced-motion: reduce)` — переворот и блик отключаются |

### 2. Архив счёта пользователей по email — лист «Сапёр» в KIP8_Access

**По заявке — НОВАЯ СТРАНИЦА В ФАЙЛЕ KIP8_Access** (не отдельный файл, как у
PhonebookArchive): `scripts/MinesweeperArchive.gs` открывает KIP8_Access по
тому же ID, что `RoleMatrix.gs`.

| Компонент | Реализация |
|-----------|-----------|
| Лист «Сапёр» | строки 1–2 — титул/описание (объединение на всю ширину при закреплении ТОЛЬКО строк — уроки RoleMatrixInit v3/v4), строка 3 — заголовки, данные со строки 4: `id / дата / email / имя / результат / сложность / поле / время_сек / мины`; текстовые колонки — формат `'@'` (Task 304); `'='`-экранирование от формул |
| `minesweeper.recordResult` | `{token, won, time, diff, cols, rows, mines}` → `{id, saved}`. Валидация (отклонение, не обрезка): `won` строго bool, время 0..36000 с, `diff ∈ {easy, medium, hard}`, поле 4..60, мины 1..500 и меньше клеток; email — ИЗ СЕССИИ (подделать чужой счёт нельзя); LockService (автоинкремент id); аудит `MINE_RECORD_WIN / MINE_RECORD_LOSS` |
| `minesweeper.getMyArchive` | `{token}` → свои последние 50 партий (новые первыми) + `stats {total, wins, losses, best:{сложность: рекордное время побед}}`; фильтр по email — чужие записи не возвращаются |
| Гейт | `secret.view` матрицы KIP8_Access (то же право, что открывает страницу «Сапёр» на клиенте); RoleMatrixGate.gs не задеплоен → отказ всем (fail-closed) |
| Создание листа | `minesweeperArchiveInit()` — разовый запуск из редактора (идемпотентен) ИЛИ лениво при первом обращении к API; диагностика — `minesweeperArchiveStatus()` |
| Маршруты | `scripts/Code.gs` — `case 'minesweeper.recordResult' / 'minesweeper.getMyArchive'` + строка в индексе модулей |

### 3. Клиентская интеграция архива (`index.html`)

- **Отправка:** конец партии (`msShowOverlay`) → `msSrvSendResult(won)` →
  `KipAuth.api('minesweeper.recordResult', …)` — fire-and-forget; без сессии —
  только локальный счёт Task 193; сбой — молча (партия уже окончена).
- **Чтение:** `msInit()` → `msSrvLoadArchive()` → `getMyArchive` (троттлинг
  60 с, чистая функция `msSrvThrottled`; кэш `msSrvArchiveCache` в localStorage —
  оффлайн показывает последний ответ; после записи — принудительный рефреш).
- **Блок «Архив партий»** (`#msSrvArchive`) под «Достижениями»: 5 слотов
  (✓ победа / ✗ поражение + сложность + время + дата), бейдж «N партий · M
  побед»; на мобильном — 3 слота без даты (как строка «Достижений»), слоты с
  переносом — контент не вылезает за рамки; скрыт без сессии/данных/сервера.
- **Тихая деградация:** сервер ещё без модуля (старый Apps Script отвечает
  «Unknown action») / сеть / нет токена — блок скрыт, игра работает, локальный
  счёт не зависит от сервера.
