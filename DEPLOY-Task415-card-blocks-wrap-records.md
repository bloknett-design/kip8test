# Task 415 — карта работника: перенос длинных записей в блоках

**Заявка:** «В карте работника, в блоках, записи которые не помещяются в
одну строчку должны переноситься на следующую строчку».

## Что изменилось

В карте работника записи, которые не помещаются в одну строку, теперь
**переносятся на следующую строку** — раньше длинные темы обрезались
многоточием «…». Строка растёт по высоте (зебра фона тянется на все
строки текста, свотч/код И|ПЗ и кнопки ✎/✕ остаются на месте).

Затронуты ОБЕ проекции карты:

1. **Страница «Работники»** (блоки-окна `.ws-wcard`):
   - записи мероприятий и инструктажей (`.ws-popup-name`) — переносятся;
   - заголовки блоков (`.ws-whead-t`: ФИО · таб. №, «СИЗ · средства
     индивидуальной защиты», «Повторные инструктажи … · год») — тоже
     переносятся (поведение `ws-whead-wrap` Task 405 стало поведением
     по умолчанию для всех заголовков).
2. **Попап карточки у сетки** (`#wsEmpPopup`, окно до 380px):
   - записи (включая строки «вне списка» и записи групп шаблона) —
     переносятся;
   - заголовок ФИО (`.ws-popup-title`) и заголовки секций
     (`.ws-popup-sec`) — переносятся (раньше «Повторные инструктажи и
     периодическая проверка знаний · 2026» обрезалось «…»).

**НЕ изменилось** (компактный однострочный вид с многоточием сохранён):
попап дня «Мероприятия в этот день» (`#wsEventsPopup`) и окно выбора
кодов (`#wsCellPopup`). СИЗ-наименования и значения полей профиля/отпусков
переносились и раньше — не тронуты (регресс-проверки в тестах).

## Серверные шаги

**НЕТ** — менялся только index.html (CSS). Актуальные серверные шаги
прежних задач (если ещё не выполнены): обновить WorkSchedule.gs в
Apps Script + НОВАЯ ВЕРСИЯ развёртывания + разово instrListInit
(Task 409/412/413).

## Что проверять

1. «Работники» → карточка работника с длинными темами записей:
   текст записи виден ПОЛНОСТЬЮ, строка в 2+ строки, без «…»;
2. Узкая колонка/мобайл — то же самое;
3. Клик по фамилии в сетке — попап карточки: заголовок секции
   инструктажей виден полностью, записи переносятся;
4. Клик по ячейке дня — окно «Мероприятия в этот день» осталось
   компактным однострочным (как раньше).
