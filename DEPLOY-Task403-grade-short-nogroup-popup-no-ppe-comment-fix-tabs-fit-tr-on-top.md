## Что изменилось

### 1 — столбец ФИО: «разряд» → «р.», без группы допуска

- Строка должности в ячейке сетки — **только должность со сокращённым
  словом «разряд»**: «Слесарь КИПиА 5 разряд» → «Слесарь КИПиА 5 р.»,
  склонения тоже («4 разряда» → «4 р.»). Хелпер `_shortGrade(pos)`
  (регулярка `/разряд[а-яё]*/gi` — целое слово, любой регистр, любое
  окончание).
- **Группа допуска из столбца ФИО убрана** (`_empPosLine` больше её не
  показывает). Данные группы НЕ удалены из приложения: карточка
  (строка «Группа допуска»), сводная «Общая» (колонка) и шторка правки
  (селект) — как были.
- Карточка/сводная/печать — полная должность без сокращения;
  печатная форма `_posLabel` не менялась.
- Тип работника остался третьей строкой ячейки (Task 402).

### 2 — попап шахматки: данные СИЗ убраны

- `_renderWorkerCard` без `asBlocks` (попап по клику на ячейку с
  фамилией) возвращает **b1 + b2 + b3** (профиль, отпуска, мероприятия)
  — **без блока СИЗ**. Страница «Работники» (`asBlocks`) — по-прежнему
  все четыре блока.
- Профиль в попапе не изменился (в т.ч. строка «Группа допуска»).

### 3 — БАГ КОММЕНТАРИЯ (сервер WorkSchedule.gs) — ИСПРАВЛЕН

- **Причина**: пользователь вставил столбец «группа_допуска» в лист
  «Сотрудники» **между** «должность» (J) и «комментарий» (K) —
  комментарий сместился на L. Сервер читал/писал комментарий по
  жёстким индексам J..K: в поле «комментарий» показывалась группа
  допуска, правки комментария попадали в столбец группы и затирались.
- **Фикс**: «должность» и «комментарий» теперь тоже ищутся **по
  ЗАГОЛОВКУ строки 1** — новый хелпер `_headerColIndex(sheet, variants)`
  (обобщение `_accessGroupColIndex`, Task 402; толерантно к регистру и
  пробелам). Заголовков нет — легаси-фолбэк J/K (прежнее поведение).
- `listEmployees` — читает каждый реквизит из своего столбца (чтение
  расширено до самого правого найденного); `updateEmployee` — пишет
  должность/комментарий отдельными `setValue` в свои столбцы (группа —
  прежний guard по payload); `addEmployee` — строка собирается до
  самого правого столбца, реквизиты не затирают друг друга.

### 4 — «Работники»: ярлыки по самому длинному тексту

- Ширина колонки ярлыков-вкладок — **по габаритам самого длинного
  ярлыка**: `_fitWorkersTabs()` после каждой перерисовки страницы
  временно ставит колонке `width:auto` + ярлыкам `nowrap`, снимает
  `offsetWidth` и пишет CSS-переменную `--ws-wtabs-w` на элементе
  (НЕ inline width — мобайл ≤1023px перекрывает media-правилом ленты
  `width:auto`, переменная горизонтальному скроллу не мешает).
- Фолбэк `236px` в CSS (`width: var(--ws-wtabs-w, 236px)`) — до замера
  (скрытая страница/моки). Повтор по `document.fonts.ready` (поздний
  веб-шрифт меняет ширину фамилий).

### 5 — «Работники»: блок мероприятий — между профилем и СИЗ

- `_renderWorkerCardPanels`: ЛЕВАЯ колонка — профиль + отпуска,
  ПРАВАЯ — **мероприятия (верх) + СИЗ (низ)**: блок «Мероприятия»
  перемещён в верх правой колонки — между блоками профиля и СИЗ.
- Мобайл ≤1023px — вертикальный стек колонок (порядок прежний:
  профиль → отпуска → мероприятия → СИЗ).
