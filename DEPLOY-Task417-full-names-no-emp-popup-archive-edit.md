# Task 417 — полные названия в блоках карт, попап по фамилии удалён, правка архивных записей

**Заявка:** «В блоках карт работников названия должны отображаться
в полном виде. Попап по фамилии - убери полностью окно, теперь все
подробные данные можно посмотреть в картах работников. Пытаюсь зайти
в редактирование записи до 1000В у Федосова за 2025 год, не заходит и
сообщение "Мероприятие не найдено — обновите график", хотя в правки
записей за текущий год заходит, и все записи, в том числе до 1000В
за 2025 год есть в архивной таблице Инструктажи».

## Что изменилось

### 1. Полные названия в блоках карт

В КАРТАХ работников (страница «Работники») записи блоков
«Мероприятия» и «Повторные инструктажи и периодическая проверка
знаний» показывают **полное название** темы записи (как до Task 416).

Сокращения (столбец E «сокращение» листа «Список_И_и_ПЗ»)
применяются теперь ТОЛЬКО в компактных показах:

- тултип бейджа ячейки шахматки («И — Инстр. ОТ»);
- окно «Мероприятия в этот день»;
- окно «Мероприятия» (месяц, бар под кнопками);
- список мероприятий **печати** табеля.

### 2. Попап по фамилии удалён полностью

Клик по фамилии в колонке ФИО шахматки больше **ничего не
открывает**. Удалены: окно #wsEmpPopup с кловером, onclick ячеек
ФИО, методы onEmpCellClick/_openEmpPopup, гейт _empCardAllowed,
CSS окна и hover-подсветка колонки ФИО (подсветка без действия
вводила в заблуждение).

Все подробные данные работника — **карточки страницы «Работники»**
(профиль, отпуска, мероприятия, повторные инструктажи, СИЗ; кнопка
«Работники» видна уровням edit/view).

### 3. Правка записей прошлых лет (багфикс)

**Причина:** кнопка ✎ в карточке звала `editTraining(id)`, который
искал запись только в годовом срезе `_TRAININGS` сетки. Записи
архивных лет (годовая навигация карточки, Task 408) приходят из
`instrAll`/`eventsAll` — их поиск завершался тостом «Мероприятие
не найдено — обновите график».

**Фикс:** поиск по единому пулу с приоритетом свежести:
`_TRAININGS` (срез года табеля) → `_INSTR_ALL` (архив
«Инструктажей») → `_EVENTS_ALL` (архив «Мероприятий»). Правка
записи 2025 года («до 1000 В») теперь открывает форму с темой и
датой записи. Удаление работало и раньше (сервер ищет id в обоих
листах).

## Серверные шаги

**НЕТ** — WorkSchedule.gs не менялся. Шаги Task 413 (автосоздание
листа «Инструктажи») остаются актуальными, если ещё не выполнены.

## Что проверять после обновления PWA

1. Обновить страницу (после выхода SW kipia-test-v644 — перезагрузка
   дважды или закрыть/открыть все вкладки приложения);
2. Табель → клик по фамилии — ничего не открывается;
3. «Работники» → карточка → блок «Повторные инструктажи…» — полные
   названия записей (текущий и архивные годы через ‹ год ›);
4. ✎ у записи 2025 года («до 1000 В» у Федосова) — форма правки
   открывается, дата заполнена, тоста «Мероприятие не найдено» нет;
5. Регресс: тултип бейджа и окно «Мероприятия в этот день» — по-прежнему
   сокращения из столбца E; печать табеля — сокращения.
